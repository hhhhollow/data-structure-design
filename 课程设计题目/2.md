## 一、批量增删功能

- 涉及集合运算，即原数据集 `A` 与新增数据集 `B`，或删除数据集 `C`。
- 至少包含以下基本操作：
  - 创建：`CreateSet(&T, Str)`
  - 求差：`Difference(&T, S1, S2)`
  - 求并：`Union(&T, S1, S2)`
  - 显示：`PrintSet(T)`
- 对任意一种**线性结构**存储的数据实现集合操作。

## 二、文本编辑器

- 实现文本编辑功能，并将最终的文本保存到文件中。
- 设文件每行不超过 200 字。
- 实现以下 4 条基本编辑命令：
  1. **行插入**
     - 格式：`i<行号><回车><文本>.<回车>`
     - 说明：将 `<文本>` 插入活区中第 `<行号>` 行之后。
  2. **行删除**
     - 格式：`d<行号 1>[<空格> <行号 2>]<回车>`
     - 说明：删除活区中第 `<行号 1>` 行（到第 `<行号 2>` 行）。例如：`d10 ↵` 和 `d10 14 ↵`。
  3. **活区切换**
     - 格式：`n<回车>`
     - 说明：将活区写入输出文件，并从输入文件中读入下一段，作为新的活区。
  4. **活区显示**
     - 格式：`p<回车>`

### 部分思路：采用 `LString` 块链对活动区内容进行存储

```c
#define CHUNKSIZE 80 // 可由用户定义的块大小
typedef struct Chunk { // 结点结构
    char ch[CHUNKSIZE]; // 注：原题课件中此处拼写为 CUNKSIZE
    struct Chunk *next;
} Chunk;

typedef struct { // 串的链表结构
    Chunk *head, *tail; // 串的头和尾指针
    int curlen;         // 串的当前长度
} LString;
```

在编辑系统中，整个文本编辑区可以看成是一个串，每一行是一个子串，构成一个结点。即：同一行的串用定长结构（80 个字符），行和行之间用指针相联接。灵活分配每块大小。

## 三、术语词典

- 设一个术语不超过 5 个字。
- 按术语中的前 5 个汉字的首个拼音字符（小写）作为多关键字，如“图书”的关键字为 `"t"` 和 `"s"` 对应的 asc 码，后三个关键字的数字补为 `0`。
- 建立一个链表，链表的每个节点包含：术语、5 个关键字、术语解释。
- **对该字典实现基于 LSD 的链式基数排序**。
- **在此排序的基础上，建立一个二叉平衡树**。**利用此结构**实现对术语词典的查找功能 `find(key)`，若找到关键字 `key` 的术语，则打印出该术语和该术语的解释并返回 `true`，否则返回 `false`。

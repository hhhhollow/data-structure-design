## 题目 1：单链表实现集合并集 A = A ∪ B

### 1. 题目要求
有两个集合 $A=\{1,3,5\}$ 和 $B=\{1,4,6,2\}$ 分别用两个线性表 LA 和 LB 表示，即：线性表中的数据元素即为集合中的成员。现要求一个新的集合 $A=A \cup B$。  
**提示**：单链表 `LinkList`。

### 2. 解题思路
1. **数据结构设计**：采用带头结点的单链表结构，定义结点类型 `LNode` 以及单链表指针类型 `LinkList`。
2. **算法逻辑**：
   - 分别由数组 $\{1, 3, 5\}$ 与 $\{1, 4, 6, 2\}$ 尾插法构建单链表 `LA` 与 `LB`。
   - 依次遍历 `LB` 中的每一个元素 $e$；
   - 调用 `LocateElem(LA, e)` 查访集合 $A$ 中是否已存在相同元素；
   - 若不存在，则将元素 $e$ 插入到 `LA` 的表尾；若已存在则跳过；
   - 最终 `LA` 中保存并集结果集合，输出结果验证。

### 3. 运行结果
```text
【题目1：单链表实现集合并集 A = A U B】
初始集合：
LA = { 1, 3, 5 }
LB = { 1, 4, 6, 2 }

执行并集操作后：
LA (A = A U B) = { 1, 3, 5, 4, 6, 2 }
```

### 4. 心得体会
单链表是线性表的链式存储表示，插入与删除时无需大量搬移元素，空间动态分配。通过链表实现集合并集操作时，算法时间复杂度取决于查找操作 $O(|A| \times |B|)$。本题加深了对单链表带头结点尾插法及遍历指针操作的掌握。

## 题目 2：顺序栈实现十进制转换为八进制

### 1. 题目要求
编制一个满足下列要求的程序：对于输入的任意一个非负十进制整数，输出与其等值的八进制数。  
**提示**：顺序栈 `sqStack`。

### 2. 解题思路
1. **数学原理**：基于除基取余法 $N = (N / 8) \times 8 + N \% 8$。从低位到高位依次产生八进制数的各个数位，而数位打印需从高位到低位进行，该特性契合栈结构“后进先出”（LIFO）的特点。
2. **数据结构设计**：定义包含 `base`、`top` 及容量 `size` 的顺序栈类型 `sqStack`。
3. **算法逻辑**：
   - 初始化空栈，若输入为 0 则直接压入 0；
   - 当 $N > 0$ 时，计算余数 $N \% 8$ 压栈，令 $N = N / 8$；
   - 循环直至 $N = 0$；
   - 随后依次出栈并输出栈顶数字，直到栈空为止。

### 3. 运行结果
```text
【题目2：顺序栈实现十进制转换为八进制】
示例测试1：十进制 1348 转换为八进制为：2504
示例测试2：十进制 0 转换为八进制为：0

请输入一个非负十进制整数: 2024
十进制 2024 转换为八进制为：3750
```

### 4. 心得体会
栈结构在数制转换、表达式求值和递归求解中起到了核心暂存作用。利用栈的逆序输出特性，有效解决了除基取余产生数位的次序倒置问题。通过处理 $N=0$ 边界及栈满自动倍增扩容，保证了算法鲁棒性。

## 题目 3：串的块链结构存储及插入、比较操作

### 1. 题目要求
将串“aeiou abc”以块链结构进行存储（分 2 块），至少实现操作：串插入操作 `StrInsert(&S, pos, T)`，比较操作 `int StrCompare`。

### 2. 解题思路
1. **数据结构设计**：
   - 串 `"aeiou abc"` 包含空格共 9 个字符。题目要求“分 2 块”，因此将块大小设为 `CHUNKSIZE = 5`。
   - 第一块容纳 5 个字符 `'a','e','i','o','u'`；第二块容纳 4 个有效字符 `' ','a','b','c'`，未填满单元用标字符 `'#'` 填充。
   - 定义块结点 `Chunk` 与块链串类型 `LString`（含 `head`、`tail` 及 `curlen`）。
2. **算法逻辑**：
   - `StrCompare(S, T)`：逐字符比较两串对应字符的 ASCII 码差值，若前缀相同则按串长长短判定。
   - `StrInsert(&S, pos, T)`：在串 $S$ 的第 $pos$ 个字符前插入子串 $T$。提取两串有效字符并重新按 `CHUNKSIZE` 分块重组，保持块链结构的完整性与紧凑性。

### 3. 运行结果
```text
【题目3：串以块链结构存储（分2块）及插入、比较操作】

1. 初始存储串 "aeiou abc" 为块链结构：
串 S (长度: 9): [块1: 'a' 'e' 'i' 'o' 'u' ] -> [块2: ' ' 'a' 'b' 'c' '#' ] -> NULL

2. 比较操作 StrCompare 测试：
   StrCompare(S, "aeiou 123") = 48 (S更大多以正数返回)
   StrCompare(S, "aeiou abc") = 0 (相等返回0)

3. 串插入操作 StrInsert(&S, 6, "xyz") 测试：
   在 S 的第 6 个字符前插入 "xyz"：
插入后的串 S (长度: 12): [块1: 'a' 'e' 'i' 'o' 'u' ] -> [块2: 'x' 'y' 'z' ' ' 'a' ] -> [块3: 'b' 'c' '#' '#' '#' ] -> NULL
   展开字符值: "aeiouxyz abc"
```

### 4. 心得体会
块链结构综合了顺序存储（单块内数组）与链式存储（结点间指针）的优点。既降低了纯链表结构高存储密度开销（指针占比过大），又具备链表在动态拼接与扩容时的灵活性。

## 题目 4：三元组顺序表实现稀疏矩阵相加

### 1. 题目要求
假设稀疏矩阵 A 和 B 均以三元组顺序表作为存储结构。试写出矩阵相加的算法，另设三元组表 C 存放结果矩阵。
提示：要求 A 和 B 分别是以下矩阵，打印出 C：
$$A = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 2 & 0 \\ 0 & 3 & 0 \end{bmatrix}, \quad B = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 0 & 2 \\ 0 & 3 & 0 \end{bmatrix}$$

### 2. 解题思路
1. **数据结构设计**：
   - 采用三元组 `Triple (i, j, e)` 表示行坐标、列坐标及非零元值。
   - 稀疏矩阵顺序表 `TSMat` 动态维护非零元数组 `nzElem`，按行主序升序排列。
2. **算法逻辑**：
   - 双指针 $p_a$ 和 $p_b$ 分别扫描矩阵 $A$ 与 $B$ 的非零元序列；
   - 计算元素在一维展开下的行优先位置 `pos = (i - 1) * n + j`；
   - 若 $posA < posB$，将 $A$ 的当前元放入 $C$；
   - 若 $posB < posA$，将 $B$ 的当前元放入 $C$；
   - 若 $posA == posB$，将两值相加；和不为 0 时写入 $C$；
   - 复制未处理完的非零元，更新结果矩阵非零元计数 $C \to t$。

### 3. 运行结果
```text
【题目4：三元组顺序表实现稀疏矩阵相加 C = A + B】

矩阵 A 矩阵视图 (3 x 3):
  [  1  0  0 ]
  [  0  2  0 ]
  [  0  3  0 ]

矩阵 B 矩阵视图 (3 x 3):
  [  1  0  0 ]
  [  0  0  2 ]
  [  0  3  0 ]

================ 结果矩阵 C = A + B ================
矩阵 C 的三元组表 (行数=3, 列数=3, 非零元数=4):
   序号 | 行(i) | 列(j) | 元素值(e)
  --------------------------------
     1  |   1   |   1   |    2
     2  |   2   |   2   |    2
     3  |   2   |   3   |    2
     4  |   3   |   2   |    6

矩阵 C 矩阵视图 (3 x 3):
  [  2  0  0 ]
  [  0  2  2 ]
  [  0  6  0 ]
```

### 4. 心得体会
稀疏矩阵压缩存储极大地节省了海量零元素所占用的空间。在实现加法时，通过有序三元组双指针归并思想，使得运算时间复杂度仅与非零元素个数呈线性关系 $O(t_A + t_B)$，远优于常规二维数组相加的 $O(m \times n)$ 复杂度。

## 题目 5：图的邻接表存储与普利姆算法求最小生成树

### 1. 题目要求
将右图存入邻接表，给出普利姆算法求解的最小生成树，至少实现操作：`MiniSpanTree_P(MGraph G, VertexType u)`。  
边权重：$\langle 1, 2\rangle=2, \langle 1, 3\rangle=3, \langle 5, 6\rangle=6, \langle 1, 5\rangle=5, \langle 1, 6\rangle=6, \langle 2, 3\rangle=3, \langle 2, 4\rangle=4, \langle 3, 4\rangle=3, \langle 4, 5\rangle=5, \langle 4, 6\rangle=6$。

### 2. 解题思路
1. **邻接表建立**：定义顶点结点与边表结点，将 6 个顶点和 10 条无向边录入邻接表并打印展示。
2. **普利姆算法实现**：
   - 严格按照题设函数名 `MiniSpanTree_P(MGraph G, VertexType u)` 实现；
   - 引入辅助数组 `closedge[MAX_VEX_NUM]`，其中 `adjvex` 记录跨割边在 $U$ 中的依附顶点，`lowcost` 记录从顶点集 $U$ 到 $V-U$ 的最小边权；
   - 初始将起点 $u$ 放入 $U$（`lowcost = 0`）；
   - 循环 $n-1$ 次：在 $V-U$ 中挑选 `lowcost` 最小的顶点 $k$，输出树边并将 $k$ 加入 $U$；随后以顶点 $k$ 的邻接边刷新 `closedge` 数组。

### 3. 运行结果
```text
【题目5：图的邻接表存储与普利姆算法求解最小生成树】

--- 图的邻接表存储表示 ---

顶点 [2] -> (至顶点4, 权值:4) -> (至顶点3, 权值:3) -> (至顶点1, 权值:2) -> NULL
顶点 [3] -> (至顶点4, 权值:3) -> (至顶点2, 权值:3) -> (至顶点1, 权值:3) -> NULL
顶点 [4] -> (至顶点6, 权值:6) -> (至顶点5, 权值:5) -> (至顶点3, 权值:3) -> (至顶点2, 权值:4) -> NULL
顶点 [5] -> (至顶点4, 权值:5) -> (至顶点1, 权值:5) -> (至顶点6, 权值:6) -> NULL
顶点 [6] -> (至顶点4, 权值:6) -> (至顶点1, 权值:6) -> (至顶点5, 权值:6) -> NULL

--- 普利姆算法求解最小生成树（从顶点 1 出发）---
  第 1 步选取边: (1, 2), 权值: 2
  第 2 步选取边: (1, 3), 权值: 3
  第 3 步选取边: (3, 4), 权值: 3
  第 4 步选取边: (1, 5), 权值: 5

```

### 4. 心得体会
普利姆算法基于贪心策略，通过逐步扩充生成树顶点集 $U$，利用割性质确保每一步选择轻边（权值最小的跨割边）均在某一最小生成树中。通过辅助数组 `closedge`，无需每次全局搜索所有边，有效降低了求解复杂度。

## 题目 6：二叉平衡树的构造、左平衡旋转与插入

### 1. 题目要求
构造一棵二叉平衡树，依次输入 $\{5,3,7,6,9\}$ 至少实现基本操作：左旋 `LeftBalance(BSTree &T)`，插入 `InsertAVL(BSTree &T, ElemType e, Boolean &taller)`。使用此函数插入新的节点 2 和 15 并打印结果。

### 2. 解题思路
1. **数据结构设计**：结点中维护平衡因子 `bf`（左子树高度减右子树高度），定义状态 `LH(+1)`、`EH(0)`、`RH(-1)`。
2. **旋转与平衡维护**：
   - 单旋转：`R_Rotate`（右单旋，处理 LL 型失衡）与 `L_Rotate`（左单旋，处理 RR 型失衡）；
   - `LeftBalance(BSTree *T)`：处理左子树长高引起的失衡。若左孩子为 `LH` 则进行 LL 单右旋；若左孩子为 `RH` 则进行 LR 先左旋后右旋的双旋转，并根据孙子结点的 `bf` 精确重置旋转后根与孩子的平衡因子。
   - 相应配套 `RightBalance(BSTree *T)` 处理右平衡旋转。
3. **递归插入**：
   - `InsertAVL(BSTree *T, ElemType e, Boolean *taller)`：若插入成功且导致子树长高，沿递归路径向上回溯更新 `bf`，一旦出现失衡即调用旋转平衡函数，并复位 `*taller = FALSE`。

### 3. 运行结果

1. 依次插入初始序列 {5, 3, 7, 6, 9}：
   插入节点 5 成功
   插入节点 3 成功
   插入节点 7 成功
   插入节点 6 成功
   插入节点 9 成功

当前平衡二叉树形态（横向树状图，右子树在上，左子树在下）：
            9[bf:0]
      7[bf:0]
            6[bf:0]
5[bf:-1]
      3[bf:0]
中序遍历序列: 3(bf=0) 5(bf=-1) 6(bf=0) 7(bf=0) 9(bf=0) 

2. 调用 InsertAVL 插入新节点 2：
插入节点 2 后的平衡二叉树形态：
            9[bf:0]
      7[bf:0]
            6[bf:0]

      3[bf:1]

### 4. 心得体会
普通二叉排序树在极端插入序列下可能退化为单支树（复杂度降至 $O(n)$）。AVL 树通过动态维护平衡因子与及时的局部旋转调整，使得树的高度始终维持在 $O(\log n)$，保障了检索、插入与删除的高效稳定。通过本题深入掌握了四种失衡类型的判断与旋转调整的指针变换细节。

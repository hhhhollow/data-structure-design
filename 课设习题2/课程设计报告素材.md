## 题目一：批量增删功能（线性表集合操作）

### 1. 题目要求
- 涉及集合运算，即原数据集 $A$ 与新增数据集 $B$（批量增加），或删除数据集 $C$（批量删除）；
- 至少包含以下函数操作：
  - 创建集合：`CreateSet(&T, Str)`
  - 求差集：`Difference(&T, S1, S2)`
  - 求并集：`Union(&T, S1, S2)`
  - 显示集合：`PrintSet(T)`
- 对任意一种线性结构存储的数据实现集合操作。

### 2. 解题思路
1. **数据结构设计**：
   选用带头结点的单链表 `LinkList`（`LNode`）作为线性存储结构。单链表具有动态扩容、插入与删除无需大面积移动数据的优点，贴合集合动态增删的需求。
   ```c
   typedef int ElemType;
   typedef struct LNode {
       ElemType data;
       struct LNode *next;
   } LNode, *LinkList;
   ```
2. **算法实现原理**：
   - **创建集合 `CreateSet(&T, Str)`**：初始化带头结点的单链表，解析输入字符串 `Str` 中的各数值；插入前调用 `LocateElem` 判定集合中是否已存在该元素，若不存在方可插入表尾，严格确保集合元素的互异性。
   - **求并集 `Union(&T, S1, S2)`**：初始化新集合 $T$，首先将 $S1$ 中全部元素复制到 $T$；然后遍历 $S2$，对每个元素检测是否在 $T$ 中，不在则插入 $T$ 的表尾。批量增加新数据时，即调用 `Union(&T_new, A, B)`。
   - **求差集 `Difference(&T, S1, S2)`**：初始化新集合 $T$，遍历集合 $S1$ 中的每个元素；若该元素不存在于 $S2$ 中，则将其加入 $T$ 中。批量删除数据时，即调用 `Difference(&T_new, A, C)`。
   - **显示集合 `PrintSet(T)`**：从头结点的后继开始遍历并打印各元素。

### 4. 心得体会
集合的核心特性是“无序性”与“互异性”。在单链表实现集合运算时，查找元素是否存在的时间复杂度为 $O(n)$，求并集与求差集的时间复杂度均为 $O(|S1| \times |S2|)$。通过 `CreateSet` 统一去重，确保了集合的数学严谨性。通过求并集实现批量添加、求差集实现批量删除，体现了数据抽象（ADT）对实际业务场景的高效映射。

## 题目二：简易文本编辑器（基于 LString 块链存储）

### 1. 题目要求
- 实现文本编辑功能，并将最终的文本保存到文件中；
- 设文件每行不超过 200 字；
- 采用 `LString` 块链结构对活动区内容进行存储：
  - 定长块结构（80 个字符），行和行之间用指针相联接；
- 实现以下 4 条基本编辑命令：
  - (1) **行插入**：`i<行号><回车><文本*>.<回车>`，将 `<文本>` 插入活区中第 `<行号>` 行之后；
  - (2) **行删除**：`d<行号 1>[<空格><行号 2>]<回车>`，删除活区中第 `<行号 1>` 行（到第 `<行号 2>` 行）；
  - (3) **活区切换**：`n<回车>`，将活区写入输出文件，并从输入文件中读入下一段，作为新的活区；
  - (4) **活区显示**：`p<回车>`，显示当前活区文本。

### 2. 解题思路
1. **数据结构设计**：
   - 块链结点 `Chunk`：每个结点存放定长 80 个字符（`CHUNKSIZE=80`）以及指向下一个块结点的指针 `next`。
   - 串结构 `LString`：包含头指针 `head`、尾指针 `tail` 和当前串长 `curlen`。由于每行不超过 200 字，一行文本最多跨越 3 个块链结点。
   - 行结点 `LineNode` 与活区结构 `Editor`：每一行是一条独立的 `LString`，行与行之间构成单链表，便于行级别的快速插入与删除。
   ```c
   #define CHUNKSIZE 80
   #define MAX_LINE_LEN 200

   typedef struct Chunk {
       char ch[CHUNKSIZE];
       struct Chunk *next;
   } Chunk;

   typedef struct {
       Chunk *head, *tail;
       int curlen;
   } LString;

   typedef struct LineNode {
       LString text;
       struct LineNode *next;
   } LineNode;
   ```
2. **核心编辑命令逻辑**：
   - **`p`（活区显示）**：遍历活区中的 `LineNode`，调用 `StringToCString` 还原字符并打印带行号的文本。
   - **`i`（行插入）**：根据给定行号定位到前驱行结点，依次构建新行结点并链接进入链表，行号为 0 时插入在活区第一行之前。
   - **`d`（行删除）**：定位到待删除区间的前驱结点，逐个释放指定区间内各行的 `LString` 块内存和行结点本身，维护行数计数器。
   - **`n`（活区切换）**：先将当前活区内所有行的有效文本逐行写入输出文件 `output.txt` 并清空活区；再从输入文件 `input.txt` 读取下一段文本装载入活区，实现大文本文件的分段流式编辑。
   - **持久化保存**：编辑结束时将活区剩余内容写入文件并安全关闭流。

### 4. 心得体会
串的单字符单结点链表存储密度极低（指针开销远大于字符数据）。块链串 `LString` 采用定长块存储有效字符，折中了存储密度与动态修改灵活性。将整篇文档视为行结点的单链表、每一行视为块链串的层次化设计，使文本编辑器的大跨度插入与删除操作极为高效，深刻体会到了“定长结构与链式结构复合运用”的工程优势。

## 题目三：术语词典（基于 LSD 链式基数排序与二叉平衡树检索）

### 1. 题目要求
- 设一个术语不超过 5 个字；
- 按术语中的前 5 个汉字的首个拼音字符（小写）作为多关键字，如“图书”的关键字为 ”t” 和 ”s” 对应的 ASCII 码，后三个关键字的数字补为 0；
- 建立一个链表，链表的每个节点包含：术语、5 个关键字、术语解释；
- **对该字典实现基于 LSD 的链式基数排序**；
- 在此排序的基础上，建立一个二叉平衡树（AVL Tree）；
- 利用此结构实现对术语词典的查找功能 `find(key)`，若找到关键字 `key` 的术语，则打印出该术语和该术语的解释并返回 `true`，否则返回 `false`。

### 2. 解题思路
1. **数据结构设计**：
   - 词典结点 `TermNode`：包含术语名称（32字节）、5 字节无符号字符关键字数组 `keys[5]`、释义（128字节）与指针 `next`。
   - 二叉平衡树结点 `AVLTreeNode`：包含词典信息、左右孩子指针 `lchild`、`rchild` 及平衡因子 `bf`（`LH=+1`, `EH=0`, `RH=-1`）。
   ```c
   #define KEY_NUM 5
   #define RADIX 256

   typedef struct TermNode {
       char term[32];
       unsigned char keys[KEY_NUM];
       char explanation[128];
       struct TermNode *next;
   } TermNode, *TermList;

   typedef struct AVLTreeNode {
       char term[32];
       unsigned char keys[KEY_NUM];
       char explanation[128];
       int bf;
       struct AVLTreeNode *lchild, *rchild;
   } AVLTreeNode, *AVLTree;
   ```
2. **基于 LSD 的链式基数排序原理**：
   - **多关键字性质**：高位关键字在前（`keys[0]`），低位关键字在后（`keys[4]`）。
   - **LSD（最低位优先）算法流程**：
     依次进行 5 趟分配（`Distribute`）与收集（`Collect`），循环变量 $i$ 从 4 递减至 0：
     - **分配**：建立 256 个基数队列（`front[0..255]`, `rear[0..255]`）。遍历当前链表，取结点第 $i$ 位关键字 $k = p\to\text{keys}[i]$，将该结点接入第 $k$ 个队列的队尾。
     - **收集**：从 $k=0$ 到 $255$，顺序将所有非空队列首尾相连成一条新的单链表。
     - 经过 5 趟稳定的分配与收集，链表完全按 5 关键字的字典序升序排列。
3. **二叉平衡树（AVL 树）构建与查找**：
   - 依次遍历排好序的链表结点，调用 `InsertAVL` 插入平衡树中。当插入引起失衡时，根据结点的平衡因子分别执行 `LeftBalance`（LL 单旋或 LR 双旋）或 `RightBalance`（RR 单旋或 RL 双旋），保证整棵树的高度始终保持在 $O(\log n)$。
   - **查找函数 `find(AVLTree T, const char *keyStr)`**：
     将待查拼音串补充补齐为 5 字节的多关键字，从根结点出发在 AVL 树上二分查找；若关键字匹配则打印术语与解释并返回 `true`（1），若遇到空指针则判定不存在并返回 `false`（0）。

### 4. 心得体会
基数排序是分配类排序的经典代表，无需进行关键字间的两两比较，时间复杂度为 $O(d(n+rd))$，非常适合字符串、多关键字元组的排序。LSD 从最低位排序并依靠分配的稳定性，能够自然保留之前位数的次序。在已排好序的数据基础上建立 AVL 树，配合左右单旋与双旋，克服了普通二叉查找树退化为单支链表的缺陷，使查找效率严格稳定在 $O(\log n)$，展现了多种高级数据结构组合运用的强大能力。

## 题目四：图的使用（迪杰斯特拉算法求解单源最短路径）

### 1. 题目要求
- 选做题目；
- 在本次课设中应用普里姆算法、克鲁斯卡尔算法、迪杰斯特拉算法、弗洛伊德算法中的一种或几种。

### 2. 解题思路
1. **算法选型与实际场景**：
   选用**迪杰斯特拉算法（Dijkstra）**，建立具体的应用场景——高校校园景点导游与最短路径导航网络。
2. **数据结构设计**：
   - 采用图的邻接矩阵表示法 `MGraph`，顶点数组 `vexs` 存放景点编号及名称（如校门、图书馆、教学楼等），二维数组 `arcs` 存放景点之间的道路实际距离（若不通则记为 $\infty$）。
   - 定义辅助距离信息结构 `DistInfo`（对齐课件第 7 章 Slide 27-28）：
     ```c
     typedef struct {
         int prev;    // 当前最短路径上该顶点的前驱顶点的位序
         int lowcost; // 当前最短路径的长度
     } DistInfo;
     ```
3. **算法流程**：
   - 初始化：源点 $v_0$ 的距离为 0 并加入已确定集合 $U$（`final[v0]=1`），其余各顶点依据直接相连道路距离初始化 `Dist` 数组及前驱顶点 `prev`。
   - 主循环：在剩余未确定的顶点集合 $V-U$ 中挑选 `lowcost` 最小的顶点 $k$，将其标记并入 $U$；随后以 $k$ 为中继点，松弛更新所有与其相邻且未确定顶点的最短距离与前驱指针。
   - 路径回溯：通过 `Dist[dest].prev` 逆向回溯并输出完整的点对点导航路径序列。

### 4. 心得体会
迪杰斯特拉算法是贪心策略在图论中的典型应用。其核心证明在于：每次从未访问集合中选出的距离源点最近的顶点，其最短距离已经确定（因为图中无负权边，其他迂回路径只可能更长）。通过维护前驱数组 `prev`，不仅可以求得最短距离数值，更能够精确重构出完整的路径轨迹，非常贴近现代地图导航系统的底层路由原理。

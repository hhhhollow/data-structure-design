## 章节内容速览

- **第二章 线性表**：线性结构的特征、ADT List 与 13 个基本操作、顺序映像（`SqList`、地址公式、`ListInsert_Sq`/`ListDelete_Sq` 平均移动量推导）、链式映像（单链表 / 带头结点链表 / 双向链表 / 循环链表 / 有序表，含全部增删查改算法）、一元多项式的表示与 `AddPolyn`。
- **第三章 栈和队列**：栈与队列的 ADT、顺序栈 / 链栈、链队列 / 循环队列（队空、队满、队长判定公式）、六个应用实例（数制转换、括号匹配、行编辑、迷宫求解、表达式求值即中缀转后缀、递归实现）。
- **第四章 串**：ADT String 的 13 种操作与最小操作子集、定长顺序 / 堆分配 / 块链三种存储、BF 朴素匹配、首尾匹配、KMP 算法（`next` 与 `nextval` 的定义、手工计算、`get_next`/`get_nextval`、匹配推演、复杂度对比）。
- **第五章 数组和广义表**：数组 ADT 与行列优先地址公式、n 维数组映象函数、稀疏矩阵三种压缩存储（三元组顺序表、行逻辑链接顺序表、十字链表）与快速转置 `FastTransposeSMatrix`、广义表 ADT 与头尾 / 子表分析表示、六个递归函数（求深度、复制、创建、删除等）与递归设计方法。
- **第六章 树和二叉树**：树的术语与 ADT、二叉树定义与 5 条性质、两类特殊二叉树、顺序 / 二叉链表 / 三叉链表 / 双亲链表存储、四种遍历（递归与非递归、层次）、由遍历序列还原二叉树、遍历应用、中序线索化与线索遍历、树与森林的三种存储及与二叉树转换、树与森林遍历、哈夫曼树与哈夫曼编码。
- **第七章 图**：图的 ADT、四种存储结构（邻接矩阵、邻接表、十字链表、邻接多重表）、DFS / BFS、最小生成树（Prim、Kruskal）、关节点与重连通分量、最短路径（Dijkstra、Floyd）、拓扑排序、关键路径（`ve`/`vl`/`ee`/`el` 完整推演）。
- **第九章 查找**：查找表概念、顺序查找、折半查找（判定树与 ASL 推导）、次优查找树、索引顺序表、二叉排序树（查找 / 插入 / 删除）、二叉平衡树（四种旋转）、B- 树 / B+ 树 / 键树、哈希表（构造哈希函数、处理冲突、查找与 ASL、删除）。

## 使用说明

1. **图片**：全部插图在 `assets/` 下，按章分目录，md 中使用相对路径引用。**请保持 `上课课件笔记/` 整个目录结构不变**，移动或单独拷贝 md 文件会导致图片失效。
2. **排版**：建议用 Typora、Obsidian、VS Code（Markdown 预览）打开；表格、代码块、公式均按标准 Markdown 编写。
3. **页码对照**：每个 `##` / `###` 小节开头都有 `> 课件页码：Pn–Pm`，可直接翻回原 PDF 对应页核对原图与动画。
4. **图片说明**：插图是对应课件的整页渲染（含原图注），图下方 `*图 X-Y …（课件 Pn）*` 标明图号与原始页码。

## 整理原则

- **忠于课件**：只整理课件中出现的内容，不编造算法或结论；课件只给文字描述而未给代码的地方，笔记如实说明（如第七章 Dijkstra / Floyd / Kruskal 的 C 实现、第六章层次遍历队列算法，均在正文用「说明」标注为教材配套参考实现）。
- **结构重排**：把课件碎片化的版式文字重新组织为「定义 → 性质 → 算法思想 → 代码 → 示例推演 → 复杂度/对比」的层次；表格化内容（操作定义、ASL、复杂度、存储结构对比）转为 Markdown 表格。
- **代码整理**：被 PPT 版面切断的 C 语句按语法合并，统一缩进；函数名、参数、常量保持不变。课件本身的明显笔误（如 `=` 与 `==` 混用、`Lnode`/`LNode`、`FALE`→`FALSE`、`Typedef`→`typedef` 等）已修正，个别影响理解处已在正文注明。
- **配图**：从原 PDF 渲染了含示意图 / 结构图 / 过程演示的页面作为插图（共 104 张），纯文字页不重复截图。
- **删除**：页脚水印「内部学习资料，禁止上传或共享」、页码、PPT 装饰性文字均已去除。

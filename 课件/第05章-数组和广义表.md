## 5.1 数组的类型定义
> 课件页码：P2–P8

### 一、数组的抽象数据类型定义
> 课件页码：P2

数组可看成线性结构的推广：n 维数组的每个元素由 n 个下标确定，第 i 个下标 j_i 的取值范围为 0 ~ b_i-1。

```text
ADT Array {
  数据对象：D＝{ a(j1, j2, …, jn) | ji = 0, …, bi-1, i = 1, 2, …, n }
  数据关系：R＝{ R1, R2, …, Rn }
           Ri＝{ <a(j1, …, ji, …, jn), a(j1, …, ji+1, …, jn)> |
                 0 ≤ jk ≤ bk-1，1 ≤ k ≤ n 且 k ≠ i，0 ≤ ji ≤ bi-2 }
} ADT Array
```

- n 为数组的维数，b_i 为第 i 维的长度，第 i 维下标取值为 0 ~ b_i-1；
- R_i 描述第 i 维上相邻的两个元素：第 i 个下标加 1 得到该维上的后继元素，每个元素最多有 n 个直接前驱和 n 个直接后继。

### 二、二维数组的定义
> 课件页码：P3

```text
数据对象：D = { a(i, j) | 0 ≤ i ≤ b1-1，0 ≤ j ≤ b2-1 }
数据关系：R = { ROW, COL }
          ROW = { <a(i, j), a(i+1, j)> | 0 ≤ i ≤ b1-2，0 ≤ j ≤ b2-1 }
          COL = { <a(i, j), a(i, j+1)> | 0 ≤ i ≤ b1-1，0 ≤ j ≤ b2-2 }
```

ROW 为行关系、COL 为列关系，分别描述同一行、同一列内相邻元素之间的前驱/后继关系。

### 三、数组的基本操作
> 课件页码：P4–P8

| 操作 | 功能 |
| --- | --- |
| `InitArray(&A, n, bound1, …, boundn)` | 构造数组 |
| `DestroyArray(&A)` | 销毁数组 |
| `Value(A, &e, index1, …, indexn)` | 取数组元素的值 |
| `Assign(&A, e, index1, …, indexn)` | 给数组元素赋值 |

- **InitArray(&A, n, bound1, …, boundn)（P5）** 操作结果：若维数 n 和各维长度合法，则构造相应的数组 A，并返回 OK。
- **DestroyArray(&A)（P6）** 操作结果：销毁数组 A。
- **Value(A, &e, index1, …, indexn)（P7）** 初始条件：A 是 n 维数组，e 为元素变量，随后是 n 个下标值；操作结果：若各下标不超界，则 e 赋值为所指定的 A 的元素值，并返回 OK。
- **Assign(&A, e, index1, …, indexn)（P8）** 初始条件同上；操作结果：若下标不超界，则将 e 的值赋给所指定的 A 的元素，并返回 OK。

## 5.2 数组的顺序表示和实现
> 课件页码：P9–P11

### 一、数组的顺序存储特点
> 课件页码：P9

数组的类型特点：1) 只有引用型操作，没有加工型操作；2) 数组是多维的结构，而存储空间是一个一维的结构。

要把多维数组放进一维的存储空间，就要约定元素的存放次序。有两种顺序映象的方式：1) 以行序为主序（低下标优先）；2) 以列序为主序（高下标优先）。

### 二、二维数组的存储地址计算
> 课件页码：P10

以“行序为主序”的存储映象：先存第 1 行，再存第 2 行……每行内按列从左到右存放。二维数组 A 中任一元素 a(i, j) 的存储位置为

```text
LOC(i, j) = LOC(0, 0) + (b2 × i + j) × L
```

其中 LOC(0, 0) 称为基地址（基址），b2 为数组第二维（列）的长度，L 为每个元素占用的存储单元数。

例如 A 是 2 行 3 列（b2 = 3）的二维数组，按行序存储的次序为

```text
a(0,0)  a(0,1)  a(0,2)  a(1,0)  a(1,1)  a(1,2)
  0       1       2       3       4       5      ← 相对位置
```

例如 a(1, 2) 的相对位置为 (3×1 + 2) = 5，即 LOC(1, 2) = LOC(0, 0) + 5L。

若以“列序为主序”存储，则第 1 维（行）下标变化最快：先存第 1 列，再存第 2 列……，地址计算与行序为主序时正好把两个下标的“权”互换：

```text
LOC(i, j) = LOC(0, 0) + (i + b1 × j) × L
```

其中 b1 为数组第一维（行）的长度。以列序为主序时，2 行 3 列的数组的存储次序为 a(0,0)、a(1,0)、a(0,1)、a(1,1)、a(0,2)、a(1,2)。

### 三、n 维数组的存储地址计算
> 课件页码：P11

把二维数组的地址公式推广到一般情况，可得到 n 维数组数据元素存储位置的映象关系：

```text
LOC(j1, j2, …, jn) = LOC(0, 0, …, 0) + c1×j1 + c2×j2 + … + cn×jn
其中  cn = L，  c(i-1) = bi × ci （1 < i ≤ n）
即    LOC(j1, j2, …, jn) = LOC(0, 0, …, 0) + Σ(i = 1..n) ci × ji
```

该关系称为 n 维数组的映象函数；数组元素的存储位置是其下标的线性函数。

- c_n = L：最后一维下标每增加 1，地址只增加一个元素所占的存储单元数；
- c(i-1) = b_i × c_i：第 i-1 维下标每增加 1，跨过第 i 维的一整行（长度为 b_i），所以系数是 b_i 与 c_i 的乘积；
- 也就是说，c_i 是第 i 维下标每增加 1 所跨过的存储单元数，离第一维越远、下标变化引起的地址变化越小（低维优先）。

## 5.3 稀疏矩阵的压缩存储
> 课件页码：P12–P33

### 一、稀疏矩阵的定义与存储问题
> 课件页码：P12–P15

**何谓稀疏矩阵（P12）** 假设 m 行 n 列的矩阵含 t 个非零元素，则称

```text
δ = t / (m × n)
```

为稀疏因子。通常认为 δ ≤ 0.05 的矩阵为稀疏矩阵。

**常规方法表示高阶稀疏矩阵的问题（P13）** 1) 零值元素占了很大空间；2) 计算中进行了很多和零值的运算，遇除法，还需判别除数是否为零。

**解决问题的原则（P14）** 1) 尽可能少存或不存零值元素；2) 尽可能减少没有实际意义的运算；3) 操作方便，即能尽可能快地找到与下标值 (i, j) 对应的元素，能尽可能快地找到同一行或同一列的非零值元。

**两类稀疏矩阵（P15）**

| 类别 | 特点 | 例 |
| --- | --- | --- |
| 特殊矩阵 | 非零元在矩阵中的分布有一定规则 | 三角矩阵、对角矩阵 |
| 随机稀疏矩阵 | 非零元在矩阵中随机出现 | —— |

随机稀疏矩阵的压缩存储方法有三种：一、三元组顺序表；二、行逻辑联接的顺序表；三、十字链表。

### 二、三元组顺序表
> 课件页码：P17–P25

**结构定义（P17）** 只存储非零元，每个非零元用（行下标 i，列下标 j，值 e）三元组表示，所有三元组按行序存放在顺序表中。

```c
#define MAXSIZE 12500
typedef struct {
    int i, j;           // 该非零元的行下标和列下标
    ElemType e;         // 该非零元的值
} Triple;               // 三元组类型

typedef struct {
    Triple data[MAXSIZE + 1];
    int mu, nu, tu;     // 矩阵的行数、列数和非零元个数
} TSMatrix;             // 稀疏矩阵类型
```

**转置示例（P18）** 如图 5-2 所示，课件以 3 行 5 列的矩阵 M 及其转置 T 说明转置运算。

![矩阵 M 及其转置矩阵 T](assets/第05章数组和广义表/p018.jpg)

*图 5-2 矩阵 M 及其转置矩阵 T（课件 P18）*

**常规的二维数组表示时的算法（P19）**

```c
for (col = 1; col <= nu; ++col)
    for (row = 1; row <= mu; ++row)
        T[col][row] = M[row][col];
```

其时间复杂度为 O(mu × nu)。

**用“三元组”表示时如何实现（P20）** 转置后每个三元组只是把行、列下标互换：M 的 (i, j, e) 对应 T 的 (j, i, e)。但 T 的三元组表仍须按行序有序存放，因此不能只做简单交换，还要确定每个三元组在 T 中的位置。

![三元组表的转置对应关系](assets/第05章数组和广义表/p020.jpg)

*图 5-3 M 与 T 的三元组表及其位置对应关系（课件 P20）*

如图 5-3 所示，按行序存放时 M 的第 1 个三元组 (1, 2, 14) 要放到 T.data 的第 2 个位置，M 的第 4 个三元组 (3, 1, 36) 要放到 T.data 的第 1 个位置。

**快速转置（P21–P24）** 首先应该确定每一行的第一个非零元在三元组中的位置。对 M 而言，“转置后 T 的第 col 行”就是“M 的第 col 列”：

| col | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| num[col] | 1 | 2 | 0 | 1 | 1 |
| cpot[col] | 1 | 2 | 4 | 4 | 5 |

- num[col]：M 中第 col 列的非零元个数，即 T 中第 col 行的非零元个数；
- cpot[col]：T 中第 col 行第一个非零元在 T.data 中的位置，由 num 递推求得。

```c
cpot[1] = 1;
for (col = 2; col <= M.nu; ++col)
    cpot[col] = cpot[col - 1] + num[col - 1];
```

快速转置：先统计 M 每一列的非零元个数 num，求出各行首元位置 cpot，再按 M.data 的次序扫描每个三元组，把它放到该列（转置后该行）的当前位置，同时该列的位置指针后移。

```c
Status FastTransposeSMatrix(TSMatrix M, TSMatrix &T) {
    T.mu = M.nu;
    T.nu = M.mu;
    T.tu = M.tu;
    if (T.tu) {
        for (col = 1; col <= M.nu; ++col)
            num[col] = 0;
        for (t = 1; t <= M.tu; ++t)
            ++num[M.data[t].j];
        cpot[1] = 1;
        for (col = 2; col <= M.nu; ++col)
            cpot[col] = cpot[col - 1] + num[col - 1];
        for (p = 1; p <= M.tu; ++p) {       // 转置矩阵元素
            col = M.data[p].j;
            q = cpot[col];
            T.data[q].i = M.data[p].j;
            T.data[q].j = M.data[p].i;
            T.data[q].e = M.data[p].e;
            ++cpot[col];
        } // for p
    } // if
    return OK;
} // FastTransposeSMatrix
```

以 P18 的示例矩阵为例：扫描到 M.data 的第 4 个三元组 (3, 1, 36) 时，col = 1、q = cpot[1] = 1，于是 T.data[1] = (1, 3, 36)，随后 cpot[1] 加 1。

**时间复杂度分析（P24）**

```c
for (col = 1; col <= M.nu; ++col) … …          // O(M.nu)
for (t = 1; t <= M.tu; ++t) … …                // O(M.tu)
for (col = 2; col <= M.nu; ++col) … …          // O(M.nu)
for (p = 1; p <= M.tu; ++p) … …                // O(M.tu)
```

时间复杂度为：O(M.nu + M.tu)。

**三元组顺序表的特点（P25）** 三元组顺序表又称有序的双下标法。它的特点是：非零元在表中按行序有序存储，因此便于进行依行顺序处理的矩阵运算。然而，若需随机存取某一行中的非零元，则需从头开始进行查找。

### 三、行逻辑联接的顺序表
> 课件页码：P25–P32

**结构定义（P26）** 修改前述的稀疏矩阵的结构定义，增加一个数据成员 rpos，其值在稀疏矩阵的初始化函数中确定；rpos[row] 指示第 row 行第一个非零元在 data 中的位置，从而可直接定位到某一行。

```c
#define MAXMN 500
typedef struct {
    Triple data[MAXSIZE + 1];
    int rpos[MAXMN + 1];
    int mu, nu, tu;
} RLSMatrix;            // 行逻辑链接顺序表类型
```

**给定一组下标，求矩阵的元素值（P27）**

```c
ElemType value(RLSMatrix M, int r, int c) {
    p = M.rpos[r];
    while (M.data[p].i == r && M.data[p].j < c)
        p++;
    if (M.data[p].i == r && M.data[p].j == c)
        return M.data[p].e;
    else return 0;
} // value
```

借助 rpos[r]，查找从第 r 行的第一个非零元开始逐列比较，不必从整个三元组表的表头开始查找。

**矩阵乘法的经典算法（P28）**

```c
for (i = 1; i <= m1; ++i)
    for (j = 1; j <= n2; ++j) {
        Q[i][j] = 0;
        for (k = 1; k <= n1; ++k)
            Q[i][j] += M[i][k] * N[k][j];
    }
```

其时间复杂度为：O(m1 × n2 × n1)。

**两个稀疏矩阵相乘（Q = M × N）的过程（P29）**

```text
Q 初始化；
if (Q 是非零矩阵) {                    // 逐行求积
    for (arow = 1; arow <= M.mu; ++arow) {   // 处理 M 的每一行
        ctemp[] = 0;                          // 累加器清零
        计算 Q 中第 arow 行的积并存入 ctemp[] 中；
        将 ctemp[] 中非零元压缩存储到 Q.data；
    } // for arow
} // if
```

**稀疏矩阵相乘的算法（P30–P31）**

```c
Status MultSMatrix(RLSMatrix M, RLSMatrix N, RLSMatrix &Q) {
    if (M.nu != N.mu) return ERROR;
    Q.mu = M.mu;
    Q.nu = N.nu;
    Q.tu = 0;
    if (M.tu * N.tu != 0) {                     // Q 是非零矩阵
        for (arow = 1; arow <= M.mu; ++arow) {  // 处理 M 的每一行
            ctemp[] = 0;                        // 当前行各元素累加器清零
            Q.rpos[arow] = Q.tu + 1;
            for (p = M.rpos[arow]; p < M.rpos[arow + 1]; ++p) {
                // 对当前行中每一个非零元
                brow = M.data[p].j;
                if (brow < N.nu) t = N.rpos[brow + 1];
                else { t = N.tu + 1; }
                for (q = N.rpos[brow]; q < t; ++q) {
                    ccol = N.data[q].j;         // 乘积元素在 Q 中列号
                    ctemp[ccol] += M.data[p].e * N.data[q].e;
                } // for q
            } // 求得 Q 中第 crow( = arow) 行的非零元
            for (ccol = 1; ccol <= Q.nu; ++ccol)
                if (ctemp[ccol]) {
                    if (++Q.tu > MAXSIZE) return ERROR;
                    Q.data[Q.tu].i = arow;
                    Q.data[Q.tu].j = ccol;
                    Q.data[Q.tu].e = ctemp[ccol];
                } // if
        } // for arow
    } // if
    return OK;
} // MultSMatrix
```

**时间复杂度分析（P32）**

- 累加器 ctemp 初始化的时间复杂度为 O(M.mu × N.nu)；
- 求 Q 的所有非零元的时间复杂度为 O(M.tu × N.tu / N.mu)；
- 进行压缩存储的时间复杂度为 O(M.mu × N.nu)。

总的时间复杂度就是 O(M.mu × N.nu + M.tu × N.tu / N.mu)。

若 M 是 m 行 n 列的稀疏矩阵，N 是 n 行 p 列的稀疏矩阵，则 M.tu = δ_M × m × n，N.tu = δ_N × n × p，相乘算法的时间复杂度就是 O(m × p × (1 + n × δ_M × δ_N))；当 δ_M < 0.05 和 δ_N < 0.05 及 n < 1000 时，相乘算法的时间复杂度就相当于 O(m × p)。

## 5.4 广义表的类型定义
> 课件页码：P34–P39

### 一、广义表的抽象数据类型定义
> 课件页码：P34

```text
ADT Glist {
  数据对象：D＝{ ei | i = 1, 2, …, n;  n ≥ 0;
                   ei∈AtomSet 或 ei∈GList，AtomSet 为某个数据对象 }
  数据关系：LR＝{ <ei-1, ei> | ei-1, ei∈D，2 ≤ i ≤ n }
} ADT Glist
```

- 数据对象中的 e_i 既可能取自原子集合 AtomSet，也可能本身又是一个广义表；
- 数据关系 LR 是相邻元素之间的前驱/后继关系。

### 二、广义表的定义与例子
> 课件页码：P35

广义表是递归定义的线性结构：LS = ( α1, α2, …, αn )，其中 αi 或为原子，或为广义表。例如：

```text
A = ( )
F = ( d, (e) )
D = ( (a, (b, c)), F )
C = ( A, D, F )
B = ( a, B ) = ( a, (a, (a, … ) ) )
```

- A 是空表；F 只有一个子表 (e)；
- D 的第 1 个元素是子表 (a, (b, c))，第 2 个元素是广义表 F；
- C 的元素 A、D、F 都是广义表，体现了广义表可以共享；
- B 的表尾又指向 B 自身，是递归的表。

### 三、广义表是多层次的线性结构
> 课件页码：P36

例如 D = (E, F)，其中 E = (a, (b, c))，F = (d, (e))。按层次展开：

```text
D
├── E
│   ├── a
│   └── (b, c)
│       ├── b
│       └── c
└── F
    ├── d
    └── (e)
        └── e
```

D 的第一层元素是 E、F；E 的第一层元素是原子 a 和子表 (b, c)；(b, c) 又分解为原子 b、c。可见广义表是一个多层次的线性结构。

### 四、广义表的结构特点
> 课件页码：P37–P38

广义表 LS = ( α1, α2, …, αn ) 的结构特点：

1. 广义表中的数据元素有相对次序；
2. 广义表的长度定义为最外层包含元素个数；
3. 广义表的深度定义为所含括弧的重数；注意：“原子”的深度为 0，“空表”的深度为 1；
4. 广义表可以共享；
5. 广义表可以是一个递归的表；递归表的深度是无穷值，长度是有限值；
6. 任何一个非空广义表 LS = ( α1, α2, …, αn ) 均可分解为表头 Head(LS) = α1 和表尾 Tail(LS) = ( α2, …, αn ) 两部分。

| 广义表 | Head | Tail |
| --- | --- | --- |
| D = (E, F) = ((a, (b, c)), F) | E | (F) |
| E = (a, (b, c)) | a | ((b, c)) |
| ((b, c)) | (b, c) | ( ) |
| (b, c) | b | (c) |
| (c) | c | ( ) |

注意：表头 Head(LS) 可以是原子，也可以是广义表；表尾 Tail(LS) 一定是广义表（由表中除表头外的其余元素构成的表）。

## 5.6 广义表操作的递归函数

### 一、递归函数的概念
> 课件页码：P46–P48

一个含直接或间接调用本函数语句的函数被称之为递归函数，它必须满足以下两个条件：1) 在每一次调用自己时，必须是（在某种意义上）更接近于解；2) 必须有一个终止处理或计算的准则。

**例如：梵塔的递归函数（P47）**

```c
void hanoi(int n, char x, char y, char z) {
    if (n == 1)
        move(x, 1, z);
    else {
        hanoi(n - 1, x, z, y);
        move(x, n, z);
        hanoi(n - 1, y, x, z);
    }
}
```

**例如：二叉树的遍历（P48）**

```c
void PreOrderTraverse(BiTree T, void (Visit)(BiTree P)) {
    if (T) {
        Visit(T->data);
        PreOrderTraverse(T->lchild, Visit);
        PreOrderTraverse(T->rchild, Visit);
    }
} // PreOrderTraverse
```

### 二、递归函数的设计方法
> 课件页码：P49–P54

如何设计递归函数？有三种方法：一、分治法（Divide and Conquer，又称分割求解法）；二、后置递归法（Postponing the work）；三、回溯法（Backtracking）。

**分治法（P50）** 对于一个输入规模为 n 的函数或问题，用某种方法把输入分割成 k (1 < k ≤ n) 个子集，从而产生 l 个子问题，分别求解这 l 个问题，得出 l 个问题的子解，再用某种方法把它们组合成原来问题的解。若子问题还相当大，则可以反复使用分治法，直至最后所分得的子问题足够小，以至可以直接求解为止。

**分治导致递归（P51–P53）** 在利用分治法求解时，所得子问题的类型常常和原问题相同，因而很自然地导致递归求解。

例如：梵塔问题 Hanoi(n, x, y, z)（P52）：将 n 个盘分成两个子集（1 至 n-1 和 n），从而产生三个子问题：1) 将 1 至 n-1 号盘从 x 轴移动至 y 轴；2) 将 n 号盘从 x 轴移动至 z 轴；3) 将 1 至 n-1 号盘从 y 轴移动至 z 轴。其中第 1、3 两个子问题与原问题同型，可递归求解，例如第 1 个子问题即 Hanoi(n-1, x, z, y)。

又如：遍历二叉树 Traverse(BT)（P53）：将 n 个结点分成三个子集（根结点、左子树和右子树），从而产生三个子问题：1) 访问根结点；2) 遍历左子树；3) 遍历右子树。其中第 2、3 两个子问题可递归求解 Traverse(LBT)、Traverse(RBT)。

**广义表的分治求解（P54）** 广义表从结构上可以分解成“表头 + 表尾”，或者“子表1 + 子表2 + … + 子表n”，因此常利用分治法求解之。算法设计中的关键问题是，如何将 l 个子问题的解组合成原问题的解。

### 四、例一：求广义表的深度
> 课件页码：P56–P59

5.6 节以三个例子说明广义表操作的递归函数：例一 求广义表的深度，例二 复制广义表，例三 创建广义表的存储结构（P56）。

**算法思想（P57）** 广义表的深度 = Max{子表的深度} + 1。可以直接求解的两种简单情况为：空表的深度 = 1；原子的深度 = 0。将广义表分解成 n 个子表，分别（递归）求得每个子表的深度，再取最大值加 1。

**算法（P58）**

```c
int GlistDepth(Glist L) {
    // 返回指针 L 所指的广义表的深度
    if (!L) return 1;                       // 空表的深度 = 1
    if (L->tag == ATOM) return 0;           // 原子的深度 = 0
    for (max = 0, pp = L; pp; pp = pp->ptr.tp) {
        dep = GlistDepth(pp->ptr.hp);       // 求以 pp->ptr.hp 为头指针的子表深度
        if (dep > max) max = dep;
    }
    return max + 1;
} // GlistDepth
```

**执行过程（P59）** for 循环沿表尾链 tp 逐个考察表结点：pp 依次指向 L、L->ptr.tp、……；每次递归求以 pp->ptr.hp（当前子表）为头指针的广义表深度，保留最大值 max；遍历完所有子表后返回 max + 1。

### 五、例二：复制广义表
> 课件页码：P60–P63

**算法思想（P60）** 新的广义表由新的表头和表尾构成。可以直接求解的两种简单情况为：空表复制求得的新表自然也是空表；原子结点可以直接复制求得。将广义表分解成表头和表尾两部分，分别（递归）复制求得新的表头和表尾。

**算法描述（P61）** 若 ls = NIL，则 newls = NIL；否则构造结点 newls，由表头 ls->ptr.hp 复制得 newhp，由表尾 ls->ptr.tp 复制得 newtp，并使 newls->ptr.hp = newhp，newls->ptr.tp = newtp。

**算法（P62–P63）**

```c
Status CopyGList(Glist &T, Glist L) {
    if (!L) T = NULL;                       // 复制空表
    else {
        if (!(T = (Glist)malloc(sizeof(GLNode))))
            exit(OVERFLOW);                 // 建表结点
        T->tag = L->tag;
        if (L->tag == ATOM)
            T->atom = L->atom;              // 复制单原子结点
        else {                              // 分别复制表头和表尾
            CopyGList(T->ptr.hp, L->ptr.hp);
            CopyGList(T->ptr.tp, L->ptr.tp);
        }
    } // else
    return OK;
} // CopyGList
```

语句 `CopyGList(T->ptr.hp, L->ptr.hp);` 等价于 `CopyGList(newhp, L->ptr.hp); T->ptr.hp = newhp;`，即参数 T 是引用型的，递归复制得到的新表头可以直接写回当前结点的 hp 域；表尾的复制同理。

### 六、例三：创建广义表的存储结构

**问题（P64–P65）** 对应广义表的不同定义方法，相应有不同的创建存储结构的算法。假设以字符串 S = ( α1, α2, …, αn ) 的形式定义广义表 L，建立相应的存储结构。由于 S 中的每个子串 αi 定义 L 的一个子表，从而产生 n 个子问题，即分别由这 n 个子串（递归）建立 n 个子表，再组合成一个广义表。可以直接求解的两种简单情况为：由串 “( )” 建立的广义表是空表；由单字符建立的子表只是一个原子结点。

**由子表组合成广义表（P66–P67）** 先看第一个子表和广义表的关系：广义表对应一个表结点（tag = 1），由指向广义表的头指针 L 指示，该结点的 hp 指向第一个子表的头指针。

再看相邻两个子表之间的关系：第 i 个子表和第 i+1 个子表分别由相邻表结点的 hp 指向，两者之间通过表结点相链接，可见表结点的 tp 起链接下一个子表结点（即表尾）的作用。

**算法描述（P68）** 若 S = “( )” 则 L = NIL；否则，构造第一个表结点 *L，并从串 S 中分解出第一个子串 α1，对应创建第一个子广义表 L->ptr.hp；若剩余串非空，则构造第二个表结点 L->ptr.tp，并从串 S 中分解出第二个子串 α2，对应创建第二个子广义表……依次类推，直至剩余串为空串止。

**算法（P69–P71）**

```c
void CreateGList(Glist &L, String S) {
    if (StrEmpty(S)) L = NULL;              // 创建空表
    else {
        L = (Glist)malloc(sizeof(GLNode));
        L->tag = LIST;
        p = L;
        sub = SubString(S, 2, StrLength(S) - 1);
        // 脱去串 S 的外层括弧
        do {                                // 由 sub 中所含 n 个子串建立 n 个子表
            sever(sub, hsub);               // 分离出子表串 hsub = αi
            if (StrLength(hsub) == 1) {
                p->ptr.hp = (Glist)malloc(sizeof(GLNode));
                p->ptr.hp->tag = ATOM;
                p->ptr.hp->atom = hsub;     // 创建单原子结点
            }
            else CreateGList(p->ptr.hp, hsub);      // 递归建广义表
            if (!StrEmpty(sub)) {
                p->ptr.tp = (Glist)malloc(sizeof(GLNode));
                // 建下一个子表的表结点 *(p->ptr.tp)
                p->ptr.tp->tag = LIST;
                p = p->ptr.tp;
            }
        } while (!StrEmpty(sub));
        p->ptr.tp = NULL;                   // 表尾为空表
    } // else
}
```

### 七、后置递归法：删除操作
> 课件页码：P72–P80

**后置递归法的设计思想（P72–P73）** 假如某个问题的求解过程可以分成若干步进行，并且当前这一步的解可以直接求得，则先求出当前这一步的解，对于余下的问题，若问题的性质和原问题类似，则又可递归求解。递归的终结状态是，当前的问题可以直接求解，对原问题而言，则是已走到了求解的最后一步。链表是可以如此求解的一个典型例子。例如：编写“删除单链表中所有值为 x 的数据元素”的算法。

**例：删除单链表中所有值为 x 的数据元素（P73–P76）** 分析：1) 单链表是一种顺序结构，必须从第一个结点起，逐个检查每个结点的数据元素；2) 从另一角度看，链表又是一个递归结构，若 L 是线性链表 (a1, a2, …, an) 的头指针，则 L->next 是线性链表 (a2, …, an) 的头指针。

例如已知链表 a1 → a2 → … → an：1) 若 a1 = x，则 L 仍为删除 x 后的链表头指针（删除 L->next 所指结点：`p = L->next; L->next = p->next;`，再删除余下部分）；2) 若 a1 ≠ x，则余下问题是考虑以 L->next 为头指针的链表。

```c
void delete(LinkList &L, ElemType x) {
    // 删除以 L 为头指针的带头结点的单链表中
    // 所有值为 x 的数据元素
    if (L->next) {
        if (L->next->data == x) {
            p = L->next;
            L->next = p->next;
            free(p);
            delete(L, x);
        }
        else delete(L->next, x);
    }
} // delete
```

先处理当前这一步（当前链表的第一个数据元素），余下的链表与原链表同型，故递归处理。

**例：删除广义表中所有元素为 x 的原子结点（P77–P80）** 分析：比较广义表和线性表的结构特点。相似处：都是链表结构。不同处：1) 广义表的数据元素可能还是个广义表；2) 删除时，不仅要删除原子结点，还需要删除相应的表结点。

```c
void Delete_GL(Glist &L, AtomType x) {
    // 删除广义表 L 中所有值为 x 的原子结点
    if (L) {
        head = L->ptr.hp;                   // 考察第一个子表
        if ((head->tag == Atom) && (head->atom == x)) {
            // 删除原子项 x 的情况
            p = L;
            L = L->ptr.tp;                  // 修改指针
            free(head);                     // 释放原子结点
            free(p);                        // 释放表结点
            Delete_GL(L, x);                // 递归处理剩余表项
        }
        else {
            // 第一项没有被删除的情况
            if (head->tag == LIST)          // 该项为广义表
                Delete_GL(head, x);
            Delete_GL(L->ptr.tp, x);        // 递归处理剩余表项
        }
    }
} // Delete_GL
```

删除原子项 x 时，既释放原子结点又释放包住它的表结点，并让 L 改指向表尾再递归；第一项没有被删除时，若该项是广义表则递归删除其中的 x，然后递归处理表尾。

### 八、回溯法
> 课件页码：P81–P85

**基本思想（P81–P82）** 回溯法是一种“穷举”方法：假设问题的解为 n 元组 (x1, x2, …, xn)，其中 xi 取值于集合 Si；n 元组的子组 (x1, x2, …, xi) (i < n) 称为部分解，应满足一定的约束条件。对于已求得的部分解 (x1, x2, …, xi)，若在添加 xi+1∈Si+1 之后仍然满足约束条件，则得到新的部分解 (x1, x2, …, xi+1)，之后继续添加 xi+2∈Si+2 并检查之。若对于所有取值于集合 Si+1 的 xi+1 都不能得到新的满足约束条件的部分解，则从当前子组中删去 xi，回溯到前一个部分解 (x1, x2, …, xi-1)，重新添加那些值集 Si 中尚未考察过的 xi，看是否满足约束条件；如此反复进行，直至求得满足约束条件的问题的解，或者证明问题无解。

**例一、皇后问题求解（P83）** 设四皇后问题的解为 (x1, x2, x3, x4)，其中 xi (i = 1, 2, 3, 4) ∈ Si = {1, 2, 3, 4}，约束条件为：其中任意两个 xi 和 xj 不能位于棋盘的同行、同列及同对角线。按回溯法的定义，求解过程为：解的初始值为空；首先添加 x1 = 1，之后添加满足条件的 x2 = 3，由于对所有的 x3∈{1, 2, 3, 4} 都不能找到满足约束条件的部分解 (x1, x2, x3)，则回溯到部分解 (x1)，重新添加满足约束条件的 x2 = 4，依次类推。

**算法（P84）**

```c
void Trial(int i, int n) {
    // 进入本函数时，在 n×n 棋盘前 i-1 行已放置了互不攻
    // 击的 i-1 个棋子。现从第 i 行起继续为后续棋子选择
    // 满足约束条件的位置。当求得 (i > n) 的一个合法布局
    // 时，输出之。
    if (i > n) 输出棋盘的当前布局;
    else for (j = 1; j <= n; ++j) {
        在第 i 行第 j 列放置一个棋子;
        if (当前布局合法) Trial(i + 1, n);
        移去第 i 行第 j 列的棋子;
    }
} // Trial
```

**回溯法求解的算法一般形式（P85）**

```c
void B(int i, int n) {
    // 假设已求得满足约束条件的部分解 (x1, …, xi-1)，本函数从
    // xi 起继续搜索，直到求得整个解 (x1, x2, …, xn)。
    if (i > n) 输出解;
    else while (!Empty(Si)) {
        从 Si 中取 xi 的一个值 vi∈Si;
        if (x1, x2, …, xi) 满足约束条件
            B(i + 1, n);                // 继续求下一个部分解
        从 Si 中删除值 vi;
    }
} // B
```

### 九、递归方法的综合讨论
> 课件页码：P86–P94

**递归算法与问题特性（P86）** 对于含有递归特性的问题，最好设计递归形式的算法。但也不要单纯追求形式，应在算法设计的分析过程中“就事论事”。例如，在利用分割求解设计算法时，子问题和原问题的性质相同；或者，问题的当前一步解决之后，余下的问题和原问题性质相同，则自然导致递归求解。

**递归的实现与栈（P87）** 实现递归函数，目前必须利用“栈”。一个递归函数必定能改写为利用栈实现的非递归函数；反之，一个用栈实现的非递归函数可以改写为递归函数。需要注意的是，递归函数递归层次的深度决定所需存储量的大小。

**分析工具：递归树（P88–P90）** 分析递归算法的工具是递归树，从递归树上可以得到递归函数的各种相关信息：递归树的深度即为递归函数的递归深度；递归树上的结点数目恰为函数中的主要操作重复进行的次数；若递归树蜕化为单支树或者递归树中含有很多相同的结点，则表明该递归函数不适用。

**尾递归的消除（P91–P93）** 递归函数中的尾递归容易消除。例如：先序遍历二叉树可以改写为

```c
void PreOrderTraverse(BiTree T) {
    while (T) {
        Visit(T->data);
        PreOrderTraverse(T->lchild);
        T = T->rchild;
    }
} // PreOrderTraverse
```

又如：删除单链表中值为 x 的结点（P92，L 为无头结点的单链表的头指针）

```c
void delete(LinkList &L, ElemType x) {
    // L 为无头结点的单链表的头指针
    if (L) {
        if (L->data == x) {
            p = L;
            L = L->next;
            free(p);
            delete(L, x);
        }
        else delete(L->next, x);
    }
}
```

可改写为（P93，L 为带头结点的单链表的头指针）

```c
void delete(LinkList &L, ElemType x) {
    // L 为带头结点的单链表的头指针
    p = L->next;
    pre = L;
    while (p) {
        if (p->data == x) {
            pre->next = p->next;
            free(p);
            p = pre->next;
        }
        else { pre = p; p = p->next; }
    }
}
```

**用递归方程表述时间性能（P94）** 可以用递归方程来表述递归函数的时间性能。例如：假设解 n 个圆盘的梵塔的执行时间为 T(n)，则递归方程为 `T(n) = 2T(n-1) + C`，初始条件为 `T(0) = 0`。

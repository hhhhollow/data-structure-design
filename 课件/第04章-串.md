## 4.1 串的抽象数据类型的定义

> 课件页码：P2–P27

### 一、串的定义

> 课件页码：P2

串（string）是**有限长的字符序列**，由一对单引号相括，例如 `'a string'`。

串的抽象数据类型 ADT String 的形式化定义如下：

```c
ADT String {
 数据对象：
   D = { ai | ai ∈ CharacterSet,
              i = 1, 2, ..., n,   n ≥ 0 }
 数据关系：
   R1 = { <ai-1, ai> | ai-1, ai ∈ D,
                        i = 2, ..., n }
 基本操作：
   ……（见下节）
} ADT String
```

- 数据对象中的每个元素 `ai` 取自字符集 CharacterSet，`n` 为串长，`n ≥ 0`；
- 数据关系 R1 刻画字符之间的前驱、后继关系，即串中字符依次排列。

### 二、串的 13 种基本操作

> 课件页码：P3–P21

课件在 ADT String 中定义了 13 种基本操作（P3–P4），并逐一给出初始条件与操作结果（P5–P21），汇总如下：

| 操作 | 初始条件 | 操作结果 |
| --- | --- | --- |
| `StrAssign(&T, chars)` | `chars` 是字符串常量 | 把 `chars` 赋为 `T` 的值 |
| `StrCopy(&T, S)` | 串 `S` 存在 | 由串 `S` 复制得串 `T` |
| `DestroyString(&S)` | 串 `S` 存在 | 串 `S` 被销毁 |
| `StrEmpty(S)` | 串 `S` 存在 | 若 `S` 为空串则返回 TRUE，否则返回 FALSE；`''` 表示空串，空串的长度为零 |
| `StrCompare(S, T)` | 串 `S` 和 `T` 存在 | 若 `S > T` 则返回值 `> 0`；若 `S = T` 则返回值 `= 0`；若 `S < T` 则返回值 `< 0` |
| `StrLength(S)` | 串 `S` 存在 | 返回 `S` 的元素个数，称为串的长度 |
| `Concat(&T, S1, S2)` | 串 `S1` 和 `S2` 存在 | 用 `T` 返回由 `S1` 和 `S2` 联接而成的新串 |
| `SubString(&Sub, S, pos, len)` | 串 `S` 存在，`1 ≤ pos ≤ StrLength(S)` 且 `0 ≤ len ≤ StrLength(S)-pos+1` | 用 `Sub` 返回串 `S` 的第 `pos` 个字符起、长度为 `len` 的子串 |
| `Index(S, T, pos)` | 串 `S` 和 `T` 存在，`T` 是非空串，`1 ≤ pos ≤ StrLength(S)` | 若主串 `S` 中存在和串 `T` 值相同的子串，则返回它在主串 `S` 中第 `pos` 个字符之后第一次出现的位置；否则函数值为 0 |
| `Replace(&S, T, V)` | 串 `S`、`T` 和 `V` 均已存在，且 `T` 是非空串 | 用 `V` 替换主串 `S` 中出现的所有与模式串 `T` 相等的不重叠子串 |
| `StrInsert(&S, pos, T)` | 串 `S` 和 `T` 存在，`1 ≤ pos ≤ StrLength(S)+1` | 在串 `S` 的第 `pos` 个字符之前插入串 `T` |
| `StrDelete(&S, pos, len)` | 串 `S` 存在，`1 ≤ pos ≤ StrLength(S)-len+1` | 从串 `S` 中删除第 `pos` 个字符起、长度为 `len` 的子串 |
| `ClearString(&S)` | 串 `S` 存在 | 将 `S` 清为空串 |

### 三、基本操作的典型示例

> 课件页码：P9–P19

**1. StrCompare**

```text
StrCompare('data', 'state') < 0
StrCompare('cat',  'case')  > 0
```

比较自第一个字符起逐位按字符编码进行：`'d' < 's'`，故 `data < state`；前两位相同而 `'t' > 's'`，故 `cat > case`。

**2. Concat**

```text
Concat(T, 'man', 'kind')  →  T = 'mankind'
```

**3. SubString**

```text
SubString(sub, 'commander', 4, 3) = 'man'
SubString(sub, 'commander', 1, 9) = 'commander'
SubString(sub, 'commander', 9, 1) = 'r'
```

子串为"串"中的一个字符子序列。再考察下面三个调用：

```text
SubString(sub, 'commander', 4, 7) = ?      // StrLength=9，9-4+1=6 < 7
SubString(sub, 'beijing',   7, 2) = ?      // StrLength=7，7-7+1=1 < 2
SubString(sub, 'student',   5, 0) = ''     // len = 0
```

- 前两个调用不满足 `0 ≤ len ≤ StrLength(S)-pos+1`，起始位置和子串长度之间存在约束关系，因而取不到合法子串；
- 长度为 0 的子串是"合法"串，此时得到空串 `''`。

**4. Index**

```text
假设 S = 'abcaabcaaabc'，T = 'bca'
Index(S, T, 1) = 2
Index(S, T, 3) = 6
Index(S, T, 8) = 0        // 从第 8 个字符之后已找不到完整的 T
```

"子串在主串中的位置"意指子串中的第一个字符在主串中的位序。

**5. Replace**

```text
假设 S = 'abcaabcaaabca'，T = 'bca'
若 V = 'x' ，则经置换后得到 S = 'axaxaax'
若 V = 'bc'，则经置换后得到 S = 'abcabcaabc'
```

**6. StrInsert / StrDelete**

```text
S = 'chater'，T = 'rac'
执行 StrInsert(S, 4, T) 之后得到 S = 'character'
```

即把串 `T` 插在 `S` 的第 4 个字符 `'t'` 之前。`StrDelete(&S, pos, len)` 则从第 `pos` 个字符起删除长度为 `len` 的子串。

### 五、最小操作子集与定位操作的实现

> 课件页码：P23–P25

在上述抽象数据类型定义的 13 种操作中，串赋值 `StrAssign`、串复制 `StrCopy`、串比较 `StrCompare`、求串长 `StrLength`、串联接 `Concat` 以及求子串 `SubString` 等六种操作构成串类型的**最小操作子集**。即：

- 这些操作不可能利用其他串操作来实现；
- 反之，其他串操作（除串清除 `ClearString` 和串销毁 `DestroyString` 外）都可以在这个最小操作子集上实现。

例如，可利用串比较、求串长和求子串等操作实现定位函数 `Index(S, T, pos)`，其判据为：

```text
StrCompare(SubString(S, i, StrLength(T)), T) ? 0
```

算法的基本思想：令 `i` 从 `pos` 开始，逐一检查主串 `S` 中长度为 `m`（`m = StrLength(T)`）的子串是否与 `T` 相等，一旦相等就返回该子串的起始位置 `i`；`i` 的最大取值只能到 `n-m+1`（`n = StrLength(S)`），否则剩余长度不足以容纳 `T`。

![定位函数 Index 的基本思想：i 从 pos 扫描到 n-m+1，每步取出长度 m 的子串与 T 比较](assets/第04章串/p024.jpg)

*图 4-2 用基本操作实现定位函数 Index 的示意图（课件 P24）*

```c
int Index (String S, String T, int pos) {
    // T为非空串。若主串S中第pos个字符之后存在与 T相等的子串，则返回第一个
    // 这样的子串在S中的位置，否则返回0
    if (pos > 0) {
        n = StrLength(S);  m = StrLength(T);  i = pos;
        while (i <= n-m+1) {
            SubString(sub, S, i, m);
            if (StrCompare(sub, T) != 0)  ++i;
            else return i;
        } // while
    } // if
    return 0;          // S中不存在与T相等的子串
} // Index
```

### 七、串与线性表的比较

> 课件页码：P27

## 4.2 串的表示和实现

> 课件页码：P28–P40

在程序设计语言中，串如果只是作为输入或输出的常量出现，则只需存储此串的串值，即字符序列即可；但在多数非数值处理的程序中，串也以变量的形式出现，因此还要考虑串的存储表示以及在其上实现各种操作的方法。

### 一、串的定长顺序存储表示

> 课件页码：P30–P32

类似于线性表的顺序存储结构，用一组地址连续的存储单元存储串值的字符序列。

```c
#define MAXSTRLEN 255
        // 用户可在255以内定义最大串长
typedef unsigned char Sstring[MAXSTRLEN + 1];
        // 0号单元存放串的长度
```

**特点：**

- 按这种串的表示方法实现串的运算时，其基本操作为"字符序列的复制"；
- 串的实际长度可在这个预定义长度的范围内随意设定；
- 超过预定义长度的串值则被舍去，称之为"截断"。

以串的联接算法为例，由于定长存储存在截断问题，需要分三种情况处理：

```c
Status Concat(SString S1, SString S2, SString &T) {
    // 用T返回由S1和S2联接而成的新串。若未截断，则返回TRUE，否则FALSE。
    if (S1[0] + S2[0] <= MAXSTRLEN) {          // 未截断
        T[1..S1[0]] = S1[1..S1[0]];
        T[S1[0]+1..S1[0]+S2[0]] = S2[1..S2[0]];
        T[0] = S1[0] + S2[0];
        uncut = TRUE;
    }
    else if (S1[0] < MAXSTRLEN) {              // 截断
        T[1..S1[0]] = S1[1..S1[0]];
        T[S1[0]+1..MAXSTRLEN] = S2[1..MAXSTRLEN-S1[0]];
        T[0] = MAXSTRLEN;
        uncut = FALSE;
    }
    else {                                     // 截断（仅取S1）
        T[0..MAXSTRLEN] = S1[0..MAXSTRLEN];
        // T[0] == S1[0] == MAXSTRLEN
        uncut = FALSE;
    }
    return uncut;
} // Concat
```

三种情况分别是：

1. 两个串的长度之和不超过 `MAXSTRLEN`：完整复制 `S1` 和 `S2`，返回 `TRUE`；
2. `S1` 未满而两串之和超长：复制 `S1` 的全部及 `S2` 的前 `MAXSTRLEN-S1[0]` 个字符，串被截断，返回 `FALSE`；
3. `S1` 本身已满 `MAXSTRLEN`：结果串只取 `S1`，`S2` 全部被舍去，返回 `FALSE`。

### 二、串的堆分配存储表示

> 课件页码：P33–P37

这种表示方法仍以一组地址连续的存储单元存放串值字符序列，但它们的存储空间是在程序执行过程中动态分配而得到的。

```c
typedef struct {
    char *ch;
        // 若是非空串，则按串长分配存储区，
        // 否则 ch 为 NULL
    int  length;   // 串长度
} HString;
```

通常，C 语言中提供的串类型就是以这种存储方式实现的。系统利用函数 `malloc()` 和 `free()` 进行串值空间的动态管理，为每一个新产生的串分配一个存储区，称串值共享的存储空间为"堆"。

- C 语言中的串以一个空字符为结束符，串长是一个隐含值；
- 这类串操作实现的算法为：先为新生成的串分配一个存储空间，然后进行串值的复制。

**串的联接：**

```c
Status Concat(HString &T, HString S1, HString S2) {
    // 用T返回由S1和S2联接而成的新串
    if (T.ch)  free(T.ch);        // 释放旧空间
    if (!(T.ch = (char *)
              malloc((S1.length+S2.length)*sizeof(char))))
        exit (OVERFLOW);
    T.ch[0..S1.length-1] = S1.ch[0..S1.length-1];
    T.length = S1.length + S2.length;
    T.ch[S1.length..T.length-1] = S2.ch[0..S2.length-1];
    return OK;
} // Concat
```

**求子串：**

```c
Status SubString(HString &Sub, HString S, int pos, int len) {
    // 用Sub返回串S的第pos个字符起长度为len的子串
    if (pos < 1  ||  pos > S.length
                ||  len < 0  ||  len > S.length-pos+1)
        return ERROR;
    if (Sub.ch)  free (Sub.ch);                // 释放旧空间
    if (!len)
        { Sub.ch = NULL;  Sub.length = 0; }    // 空子串
    else {                                     // 完整子串
        Sub.ch = (char *)malloc(len*sizeof(char));
        Sub.ch[0..len-1] = S[pos-1..pos+len-2];
        Sub.length = len;
    }
    return OK;
} // SubString
```

### 三、串的块链存储表示

> 课件页码：P38–P40

也可用链表来存储串值。由于串的数据元素是一个字符，它只有 8 位二进制数，因此用链表存储时，通常一个结点中存放的不是一个字符，而是一个子串。

- 存储密度 = 数据元素所占存储位 ÷ 实际分配的存储位。结点中只放一个字符时存储密度很低，故改为一个结点存放一个子串（块）。

```c
#define CHUNKSIZE 80       // 可由用户定义的块大小
typedef struct Chunk {     // 结点结构
    char ch[CHUNKSIZE];
    struct Chunk *next;
} Chunk;

typedef struct {           // 串的链表结构
    Chunk *head, *tail;    // 串的头和尾指针
    int   curlen;          // 串的当前长度
} LString;
```

例如，在编辑系统中，整个文本编辑区可以看成是一个串，每一行是一个子串，构成一个结点，即同一行的串用定长结构（80 个字符），行和行之间用指针相联接。实际应用时，可以根据问题所需来设置结点的大小。

### 四、三种存储表示小结

> 课件页码：P28–P40（归纳）

| 表示方式 | 存储结构定义 | 空间分配 | 主要特点 |
| --- | --- | --- | --- |
| 定长顺序存储 | `Sstring`，0 号单元存放串长 | 预定义长度 `MAXSTRLEN`，静态分配 | 基本操作为字符序列的复制；超长部分被截断 |
| 堆分配存储 | `HString`，`ch` 指针 + `length` | 用 `malloc()`/`free()` 动态管理"堆"空间 | 按串长分配存储区，串长不隐含；先分配空间再复制串值 |
| 块链存储 | `LString`，`Chunk` 结点链 + `curlen` | 结点动态分配，串值分散存放 | 一个结点存放一个子串，存储密度受结点结构影响；编辑系统中一行对应一个结点 |

## 4.3 串的模式匹配算法

> 课件页码：P41–P54

串的模式匹配（定位）是串的一种重要操作，很多软件，若有"编辑"菜单项的话，则其中必有"查找"子菜单项。

![4.3 串的模式匹配算法：这是串的一种重要操作](assets/第04章串/p041.jpg)

*图 4-5 模式匹配是串的重要操作（课件 P41）*

### 一、模式匹配（定位）的定义

> 课件页码：P42

```text
INDEX (S, T, pos)
```

- 初始条件：串 `S` 和 `T` 存在，`T` 是非空串，`1 ≤ pos ≤ StrLength(S)`；
- 操作结果：若主串 `S` 中存在和串 `T` 值相同的子串，返回它在主串 `S` 中第 `pos` 个字符之后第一次出现的位置；否则函数值为 0。

下面讨论以定长顺序结构表示串时的几种算法：

1. 简单算法；
2. 首尾匹配算法；
3. KMP（D.E.Knuth, V.R.Pratt, J.H.Morris）算法。

### 二、简单算法（BF 算法）

> 课件页码：P44

算法从主串 `S` 的第 `pos` 个字符和模式串 `T` 的第 1 个字符开始逐个比较：

- 若当前字符相等，则 `i`、`j` 同时后移，继续比较后继字符；
- 若当前字符不等，则本趟匹配的起始位置后移一位，即令 `i = i-j+2`、`j = 1`，指针后退重新开始匹配。

其中 `i-j+1` 是本趟匹配在主串中的起始位置，`i-j+2` 即该起始位置的下一位。

```c
int Index(SString S, SString T, int pos) {
    // 返回子串T在主串S中第pos个字符之后的位置。若不存在，
    // 则函数值为0。其中，T非空，1≤pos≤StrLength(S)。
    i = pos;   j = 1;
    while (i <= S[0] && j <= T[0]) {
        if (S[i] == T[j]) { ++i;  ++j; }   // 继续比较后继字符
        else { i = i-j+2;   j = 1; }       // 指针后退重新开始匹配
    }
    if (j > T[0])  return  i-T[0];
    else return 0;
} // Index
```

该算法在每趟失配后主串指针 `i` 都要回溯，最坏情况下（主串和模式串都由大量相同字符构成时，每趟都要比较到模式串末尾才失配）时间复杂度为 `O(n×m)`，其中 `n`、`m` 分别为主串和模式串的长度。

### 三、首尾匹配算法

> 课件页码：P45–P47

针对简单算法"先比较前缀、再逐个往后比"的做法，首尾匹配算法调整了比较顺序：

1. 先比较模式串的第一个字符；
2. 再比较模式串的最后一个字符；
3. 最后比较模式串中从第二个到第 `n-1` 个字符（`n` 为模式串的长度）。

首字符或尾字符一旦不等即可跳过本趟，从而减少中间字符的无效比较。

```c
int Index_FL(SString S, SString T, int pos) {
    sLength = S[0];  tLength = T[0];
    i = pos;
    patStartChar = T[1];  patEndChar = T[tLength];
    while (i <= sLength - tLength + 1) {
        if (S[i] != patStartChar) ++i;              // 重新查找匹配起始点
        else if (S[i+tLength-1] != patEndChar) ++i;
                                                    // 模式串的"尾字符"不匹配
        else {                                      // 检查中间字符的匹配情况
            k = 1;  j = 2;
            while (j < tLength && S[i+k] == T[j])
                { ++k;  ++j; }
            if (j == tLength)  return i;
            else  ++i;                              // 重新开始下一次的匹配检测
        }
    }
    return 0;
} // Index_FL
```

- `patStartChar`、`patEndChar` 分别是模式串的首字符和尾字符；
- 首字符与尾字符都匹配后，才进入内层 `while` 检查中间的字符，`j` 到达 `tLength` 说明整个模式串匹配成功，返回起始位置 `i`，否则 `i` 后移一位继续检测。

### 四、KMP 算法

> 课件页码：P48–P54

#### 1. 失配时可以利用的信息

KMP 算法的时间复杂度可以达到 `O(m+n)`。其依据是：当 `S[i] <> T[j]` 时，已经得到的结果是

```text
S[i-j+1 .. i-1] == T[1 .. j-1]
```

即主串中与模式串前 `j-1` 个字符对齐的部分已经匹配。若模式串自身的某个前缀与长度为 `k-1` 的后缀相等，即

```text
T[1 .. k-1] == T[j-k+1 .. j-1]
```

则有

```text
S[i-k+1 .. i-1] == T[1 .. k-1]
```

于是不必回退主串指针 `i`，只需把模式串向右移动 `j-k` 位，让 `T[k]` 与 `S[i]` 继续比较即可。`k` 的取值只取决于模式串本身，这就是模式串的 next 函数。

#### 2. next 函数的定义

模式串的 next 函数定义为：

- 当 `j = 1` 时，`next[j] = 0`；
- 当集合 `{ k | 1 < k < j，且 'p1…p(k-1)' = 'p(j-k+1)…p(j-1)' }` 非空时，`next[j] = Max{ k }`；
- 其它情况，`next[j] = 1`。

其中 `p1…p(k-1)` 和 `p(j-k+1)…p(j-1)` 分别是模式串 `T` 中从第 1 个字符起和从第 `j-k+1` 个字符起、长度均为 `k-1` 的子串。

含义：`next[j]` 表示当模式串第 `j` 个字符与主串失配时，模式串中下一个需要与主串当前字符比较的字符下标；若 `next[j] = 0`，说明模式串已无法右移与当前主串位置对齐，应让主串指针后移一位。

手工计算 next 值可归纳为：

1. `next[1] = 0`；
2. 对 `j ≥ 2`，找出 `j` 之前模式串子串 `T[1..j-1]` 的最长相等真前缀与真后缀，设其长度为 `L`，则 `next[j] = L+1`；若不存在这样的相等前后缀，则 `next[j] = 1`。

#### 3. 手工计算示例

以课件 P53 的模式串 `T = 'aaaab'` 为例，按定义逐个计算：

| j | 模式串 T[1..j] | 候选 k 与检查 | next[j] |
| --- | --- | --- | --- |
| 1 | `a` | 规定 | 0 |
| 2 | `aa` | 满足 1<k<2 的 k 不存在 | 1 |
| 3 | `aaa` | k=2：`'a'` = `'a'` 成立 | 2 |
| 4 | `aaaa` | k=2 成立；k=3：`'aa'` = `'aa'` 成立 | 3 |
| 5 | `aaaab` | k=2、3 成立；k=4：`'aaa'` = `'aaa'` 成立 | 4 |

即

```text
j       = 1  2  3  4  5
T[j]    = a  a  a  a  b
next[j] = 0  1  2  3  4
```

例如 `next[5] = 4` 的含义是：若在 `T[5] = 'b'` 处失配，说明 `T[1..4] = 'aaaa'` 已与主串匹配，而 `'aaaa'` 的最长相等前后缀是 `'aaa'`，故下一次直接用 `T[4]` 与失配处的主串字符比较，模式串右移 `5-4 = 1` 位。

#### 4. KMP 匹配算法

```c
int Index_KMP(SString S, SString T, int pos) {
    // 1≤pos≤StrLength(S)
    i = pos;   j = 1;
    while (i <= S[0] && j <= T[0]) {
        if (j == 0 || S[i] == T[j]) { ++i;  ++j; }
                                          // 继续比较后继字符
        else  j = next[j];                // 模式串向右移动
    }
    if (j > T[0])  return  i-T[0];        // 匹配成功
    else return 0;
} // Index_KMP
```

- 与简单算法的区别在于失配时的处理：`j = next[j]` 只是把模式串向右滑动，`i` 从不回退；
- `j == 0` 表示模式串第 1 个字符就失配且没有可用的部分匹配，此时 `i`、`j` 同时后移一位；
- `j > T[0]` 表示整个模式串比较完毕，匹配成功，起始位置为 `i-T[0]`。

#### 5. 匹配过程推演

以课件 P16 中的串为例：主串 `S = 'abcaabcaaabc'`（长度为 12），模式串 `T = 'bca'`（长度为 3），`pos = 1`。

先求模式串的 next 值：`next[1] = 0`；`next[2] = 1`（无相等前后缀）；`next[3] = 1`（`'b'` 与 `'c'` 不相等），即 `next = 0, 1, 1`。

匹配过程：

| 步骤 | 当前比较 | 处理 | i | j |
| --- | --- | --- | --- | --- |
| 1 | `S[1]='a'` 与 `T[1]='b'` 失配 | `j = next[1] = 0` | 1 | 0 |
| 2 | `j == 0` | `++i; ++j;` | 2 | 1 |
| 3 | `S[2]='b'` 与 `T[1]='b'` 相等 | `++i; ++j;` | 3 | 2 |
| 4 | `S[3]='c'` 与 `T[2]='c'` 相等 | `++i; ++j;` | 4 | 3 |
| 5 | `S[4]='a'` 与 `T[3]='a'` 相等 | `++i; ++j;` | 5 | 4 |
| 6 | `j = 4 > T[0] = 3` | 返回 `i-T[0] = 5-3 = 2` | — | — |

推演结果 `Index_KMP(S, T, 1) = 2`，与 4.1 节中 `Index(S, T, 1) = 2` 一致；整个过程中主串指针 `i` 从 1 递增到 5，从未回退。

#### 6. next 函数的求法（递推过程）

求 next 函数值的过程是一个递推过程，分析如下：

- 已知：`next[1] = 0`；
- 假设：`next[j] = k`，又 `T[j] = T[k]`，则 `next[j+1] = k+1`；
- 若：`T[j] <> T[k]`，则需往前回溯，检查 `T[j]` 与 `T[?]` 是否相等（令 `k = next[k]` 继续回溯，直到相等或 `k = 0`）。

这实际上也是一个匹配的过程，不同在于：主串和模式串是同一个串。对应的算法为：

```c
void get_next(SString &T, int &next[]) {
    // 求模式串T的next函数值并存入数组next
    i = 1;   next[1] = 0;   j = 0;
    while (i < T[0]) {
        if (j == 0 || T[i] == T[j])
            { ++i;  ++j;  next[i] = j; }
        else  j = next[j];
    }
} // get_next
```

#### 7. 改进的 next 函数（nextval）

还有一种特殊情况需要考虑。课件 P53 的例子：

```text
S = 'aaabaaabaaabaaabaaab'
T = 'aaaab'
```

| j | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| T[j] | a | a | a | a | b |
| next[j] | 0 | 1 | 2 | 3 | 4 |
| nextval[j] | 0 | 0 | 0 | 0 | 4 |

原因：`T[1..4]` 都是同一个字符 `'a'`。以 `j = 2` 为例，按 next 回退到 `j = 1`，而 `T[2] = T[1] = 'a'`，回退后比较的仍是同一个字符，必然再次失配；`j = 3`、`j = 4` 也有同样的问题。nextval 在这种情况下继续向前回溯，直接令 `nextval[2] = nextval[3] = nextval[4] = 0`，跳过这些无用的比较。`j = 5` 时 `T[5] = 'b'` 与 `T[4] = 'a'` 不同，故 `nextval[5] = next[5] = 4`。

改进后的求值算法为：

```c
void get_nextval(SString &T, int &nextval[]) {
    i = 1;   nextval[1] = 0;   j = 0;
    while (i < T[0]) {
        if (j == 0 || T[i] == T[j]) {
            ++i;  ++j;
            if (T[i] != T[j])  nextval[i] = j;
            else  nextval[i] = nextval[j];
        }
        else  j = nextval[j];
    }
} // get_nextval
```

要点：若 `T[i] != T[j]`，则 `nextval[i] = j`；若 `T[i] == T[j]`（回退后要比较的字符与当前字符相同），则 `nextval[i] = nextval[j]`，即沿用已经求出的修正值继续前跳。

### 五、几种模式匹配算法的比较

> 课件页码：P43–P54（归纳）

| 算法 | 失配后主串指针 `i` | 时间复杂度 | 说明 |
| --- | --- | --- | --- |
| 简单算法（BF） | 回溯到 `i-j+2` | 最坏 `O(n×m)` | 每趟失配后从模式串首字符重新比较，主串指针反复回退 |
| 首尾匹配算法 | 不匹配时后移一位，继续检测下一趟 | —（课件未给出复杂度量级） | 先比首、尾字符，再比中间字符，可减少中间字符的比较 |
| KMP 算法 | 不回溯 | `O(n+m)` | 利用 next（nextval）函数确定模式串下一次比较的位置 |

KMP 的 `O(n+m)` 来自两部分：求 next 函数需扫描一遍模式串，为 `O(m)`；匹配过程中 `i` 只增不减，`j` 的回退总量是有限的，匹配部分为 `O(n)`。

## 本章要点回顾

> 课件页码：P55–P56

1. 串是有限长的字符序列，由一对单引号相括；串的逻辑结构和线性表极为相似，区别仅在于串的数据对象约束为字符集。
2. 串的基本操作通常以"串的整体"作为操作对象，与线性表以"单个元素"为操作对象不同。
3. ADT String 定义了 13 种基本操作，其中 `StrAssign`、`StrCopy`、`StrCompare`、`StrLength`、`Concat`、`SubString` 共六种构成最小操作子集，其余操作（除 `ClearString`、`DestroyString` 外）可在该子集上实现。
4. 定长顺序存储用 `Sstring`，0 号单元存放串长；超过 `MAXSTRLEN` 的串值被截断，串联接需按"未截断、截断、仅取 `S1`"三种情况处理。
5. 堆分配存储用 `HString`（`ch` 指针 + `length`），借助 `malloc()`/`free()` 动态管理堆空间，先分配存储区再复制串值；C 语言中的串类型即以此方式实现。
6. 块链存储用 `LString`，一个结点存放一个子串（块），存储密度 = 数据元素所占存储位 ÷ 实际分配的存储位；编辑系统中可把每一行作为一个结点。
7. 定位操作 `Index(S, T, pos)` 可在最小操作子集上用"求子串 + 串比较"实现，也可在定长顺序存储结构上直接实现。
8. 简单算法（BF）失配时令 `i = i-j+2`、`j = 1`，主串指针回退，最坏时间复杂度为 `O(n×m)`。
9. 首尾匹配算法依次比较模式串的首字符、尾字符及中间的字符，用首尾字符快速排除失配情形。
10. KMP 算法在失配时主串指针 `i` 不回退，只按 next 函数右移模式串，时间复杂度为 `O(n+m)`。
11. next 函数只与模式串本身有关：`next[1] = 0`；否则取失配位置之前最长相等真前缀与真后缀的长度加 1；不存在相等前后缀时为 1。
12. 改进的 nextval 在 `T[i] == T[j]` 时令 `nextval[i] = nextval[j]`，否则令 `nextval[i] = j`，可避免回退到相同字符上的多余比较。

## 6.1 树的类型定义
> 课件页码：P2–P15

### 一、树的定义
> 课件页码：P3

**数据对象 D**：D 是具有相同特性的数据元素的集合。

- 若 D 为空集，则称为**空树**；
- 否则：
    1. 在 D 中存在唯一的称为**根**的数据元素 root；
    2. 当 n>1 时，其余结点可分为 m（m>0）个互不相交的有限集 T1, T2, …, Tm，其中每一个子集本身又是一棵符合本定义的树，称为根 root 的**子树**。

**数据关系 R**：树根和子树根之间为有向关系（课件 P9 在“有向树”中给出这一结论）。

### 二、树的基本操作
> 课件页码：P4–P7

树的基本操作分为查找类、插入类、删除类三类，操作与参数如下表。

| 类别 | 操作原型 | 说明 |
|---|---|---|
| 查找类 | `Root(T)` | 求树的根结点 |
| 查找类 | `Value(T, cur_e)` | 求当前结点的元素值 |
| 查找类 | `Parent(T, cur_e)` | 求当前结点的双亲结点 |
| 查找类 | `LeftChild(T, cur_e)` | 求当前结点的最左孩子 |
| 查找类 | `RightSibling(T, cur_e)` | 求当前结点的右兄弟 |
| 查找类 | `TreeEmpty(T)` | 判定树是否为空树 |
| 查找类 | `TreeDepth(T)` | 求树的深度 |
| 查找类 | `TraverseTree( T, Visit() )` | 遍历树 |
| 插入类 | `InitTree(&T)` | 初始化置空树 |
| 插入类 | `CreateTree(&T, definition)` | 按定义构造树 |
| 插入类 | `Assign(T, cur_e, value)` | 给当前结点赋值 |
| 插入类 | `InsertChild(&T, &p, i, c)` | 将以 c 为根的树插入为结点 p 的第 i 棵子树 |
| 删除类 | `ClearTree(&T)` | 将树清空 |
| 删除类 | `DestroyTree(&T)` | 销毁树的结构 |
| 删除类 | `DeleteChild(&T, &p, i)` | 删除结点 p 的第 i 棵子树 |

### 四、有向树、有序树与无序树
> 课件页码：P9

- **有向树**：（1）有确定的根；（2）树根和子树根之间为有向关系。
- **有序树**：子树之间存在确定的次序关系。
- **无序树**：子树之间不存在确定的次序关系。

### 五、树型结构与线性结构的对比
> 课件页码：P10–P11

树型结构和线性结构在结构特点上的区别如下表所示。

| 结构类型 | 第一个数据元素 | 最后一个数据元素 | 其它数据元素 |
|---|---|---|---|
| 线性结构 | 无前驱 | 无后继 | 一个前驱、一个后继 |
| 树型结构 | 根结点（无前驱） | 多个叶子结点（无后继） | 一个前驱、多个后继 |

可见，线性结构中每个数据元素至多有一个前驱和一个后继；树型结构中除根和叶子外，每个元素有一个前驱、多个后继，因此树是典型的非线性结构。

### 六、基本术语
> 课件页码：P12–P15

- **结点**：数据元素 + 若干指向子树的分支。
- **结点的度**：结点所拥有分支的个数。
- **树的度**：树中所有结点的度的最大值。
- **叶子结点**：度为零的结点。
- **分支结点**：度大于零的结点。
- **（从根到结点的）路径**：由从根到该结点所经分支和结点构成。
- **孩子结点、双亲结点**：若结点 X 的子树根为 Y，则 Y 是 X 的孩子结点，X 是 Y 的双亲结点。
- **兄弟结点、堂兄弟结点**：同一双亲的孩子结点互为兄弟；双亲在同一层的结点互为堂兄弟。
- **祖先结点、子孙结点**：从根到某结点路径上所经的结点是该结点的祖先；以某结点为根的子树中的任一结点都是该结点的子孙。
- **结点的层次**：假设根结点的层次为 1，第 l 层的结点的子树根结点的层次为 l+1。
- **树的深度**：树中叶子结点所在的最大层次。

### 七、森林
> 课件页码：P15

任何一棵非空树是一个二元组：

```text
Tree = ( root, F )
```

其中：root 被称为根结点；F 被称为**子树森林**。

**森林**：是 m（m≥0）棵互不相交的树的集合。删去一棵非空树的根结点，其各棵子树便构成一个森林；反之，加上一个根结点把森林中各棵树作为根的子树，又得到一棵树。

### 四、二叉树的重要特性
> 课件页码：P23–P29

#### 性质 1
**在二叉树的第 i 层上至多有 2ⁱ⁻¹ 个结点（i≥1）。**

用归纳法证明：

- **归纳基**：i=1 层时，只有一个根结点，2ⁱ⁻¹ = 2⁰ = 1，命题成立；
- **归纳假设**：假设对所有的 j（1≤j<i），命题成立，即第 j 层至多有 2ʲ⁻¹ 个结点；
- **归纳证明**：二叉树上每个结点至多有两棵子树，则第 i 层的结点数至多为第 i−1 层结点数的 2 倍，即 2ⁱ⁻² × 2 = 2ⁱ⁻¹。

#### 性质 2
**深度为 k 的二叉树上至多含 2ᵏ−1 个结点（k≥1）。**

证明：基于上一条性质，深度为 k 的二叉树上的结点数至多为

```text
2⁰ + 2¹ + … + 2ᵏ⁻¹ = 2ᵏ − 1
```

#### 性质 3
**对任何一棵二叉树，若它含有 n₀ 个叶子结点、n₂ 个度为 2 的结点，则必存在关系式：n₀ = n₂ + 1。**

证明：

```text
设二叉树上结点总数 n = n₀ + n₁ + n₂
又二叉树上分支总数 b = n₁ + 2n₂
而 b = n − 1 = n₀ + n₁ + n₂ − 1
由此，n₀ = n₂ + 1
```

#### 两类特殊的二叉树
- **满二叉树**：指的是深度为 k 且含有 2ᵏ−1 个结点的二叉树。即每一层的结点数都达到最大值，第 i 层恰有 2ⁱ⁻¹ 个结点。
- **完全二叉树**：树中所含的 n 个结点和满二叉树中编号为 1 至 n 的结点一一对应。即按从上到下、从左至右的次序编号时，编号连续、中间不缺位置。

![满二叉树与完全二叉树](assets/第06章树和二叉树/p027.jpg)

*图 6-6 两类特殊的二叉树：深度为 4 的满二叉树（编号 1~15）与完全二叉树（a~j）（课件 P27）*

#### 性质 4
**具有 n 个结点的完全二叉树的深度为 ⌊log₂n⌋ + 1。**

证明：

```text
设完全二叉树的深度为 k
则根据第二条性质得  2ᵏ⁻¹ ≤ n < 2ᵏ
即  k−1 ≤ log₂n < k
因为 k 只能是整数，因此 k = ⌊log₂n⌋ + 1
```

#### 性质 5
**若对含 n 个结点的完全二叉树从上到下且从左至右进行 1 至 n 的编号，则对完全二叉树中任意一个编号为 i 的结点：**

1. 若 i=1，则该结点是二叉树的根，无双亲；否则，编号为 ⌊i/2⌋ 的结点为其双亲结点；
2. 若 2i>n，则该结点无左孩子；否则，编号为 2i 的结点为其左孩子结点；
3. 若 2i+1>n，则该结点无右孩子结点；否则，编号为 2i+1 的结点为其右孩子结点。

性质 5 说明完全二叉树的结点编号本身就隐含了双亲与孩子的关系，因此完全二叉树特别适合用顺序结构存储（见 6.3 节）。

## 6.3 二叉树的存储结构
> 课件页码：P30–P39

二叉树的存储结构分为两类：顺序存储表示和链式存储表示。链式存储又包括二叉链表、三叉链表、双亲链表和线索链表（线索链表在 6.5 节讨论）。

### 一、二叉树的顺序存储表示
> 课件页码：P31–P32

顺序存储用一组地址连续的存储单元存放二叉树的结点，C 语言的类型描述如下：

```c
#define MAX_TREE_SIZE  100
            // 二叉树的最大结点数
typedef TElemType SqBiTree[MAX_TREE_SIZE];
            // 0号单元存储根结点
SqBiTree bt;
```

存储时按完全二叉树的编号次序自上而下、自左至右依次存放：编号为 i 的结点存入下标为 i−1 的单元，因此 0 号单元存放根结点；数组下标之间的位置关系隐含了结点之间的逻辑关系（由性质 5 确定）。

- 完全二叉树可以直接按编号顺序存入一维数组，既不浪费单元又能由下标算出双亲、孩子的位置；
- 非完全二叉树必须按完全二叉树的编号方式在数组中补上不存在的“空结点”位置，才能由下标确定结点间的关系，因此会浪费一些存储单元，顺序存储主要适用于完全二叉树。

课件 P32 的示例中，二叉树的结点 A、B、D、C、E、F 分别存放在下标 0、1、2、4、6、13 的单元中，空出的下标 3、5、7~12 对应不存在的空结点：

![二叉树顺序存储示例：结点与数组下标的对应](assets/第06章树和二叉树/p032.jpg)

*图 6-7 二叉树的顺序存储：结点 A~F 依次存放在下标 0、1、2、4、6、13 的单元（课件 P32）*

### 二、二叉树的链式存储表示
> 课件页码：P33–P39

链式存储用指针表示结点之间的逻辑关系，常用的有二叉链表、三叉链表、双亲链表等。

#### 1. 二叉链表
每个结点设三个域：数据域 data、左孩子指针域 lchild、右孩子指针域 rchild。

![二叉链表示例：root 指向根 A，每个结点含 lchild、data、rchild](assets/第06章树和二叉树/p034.jpg)

*图 6-8 二叉链表：结点结构与存储示例（课件 P34）*

```c
typedef struct BiTNode {        // 结点结构
    TElemType      data;
    struct BiTNode  *lchild, *rchild;
                                // 左右孩子指针
} BiTNode, *BiTree;
```

二叉链表是二叉树最常用的存储结构，6.4 节的各种遍历算法均以它为基础。

#### 2. 三叉链表
在二叉链表的基础上再增加一个指向双亲的指针域 parent，便于从结点直接找到其双亲。

![三叉链表示例：每个结点含 parent、lchild、data、rchild](assets/第06章树和二叉树/p036.jpg)

*图 6-9 三叉链表：结点结构与存储示例（课件 P36）*

```c
typedef struct TriTNode {       // 结点结构
    TElemType       data;
    struct TriTNode *lchild, *rchild;
                                // 左右孩子指针
    struct TriTNode *parent;    // 双亲指针
} TriTNode, *TriTree;
```

#### 3. 双亲链表
每个结点只记录数据值和双亲的位置（下标），并设置标志域区分该结点是其双亲的左孩子还是右孩子。

![双亲链表示例：每个结点含 data、parent 与 LRTag](assets/第06章树和二叉树/p038.jpg)

*图 6-10 双亲链表：结点结构（data、parent、LRTag）与存储示例（课件 P38）*

图中各结点的 parent 域存放双亲结点所在的位置，根结点的 parent 为 −1；LRTag 取 L 或 R 表示该结点是双亲的左孩子还是右孩子。

```c
typedef struct BPTNode {        // 结点结构
    TElemType  data;
    int       *parent;          // 指向双亲的指针
    char       LRTag;           // 左、右孩子标志域
} BPTNode;

typedef struct BPTree {         // 树结构
    BPTNode nodes[MAX_TREE_SIZE];
    int     num_node;           // 结点数目
    int     root;               // 根结点的位置
} BPTree;
```

#### 4. 线索链表
在线索链表的结点中增加左、右标志域，把空的左、右孩子指针分别改为指向前驱和后继的“线索”，详见 6.5 节。

### 三、各种链式存储结构的对照
> 课件页码：P33–P39

| 存储结构 | 结点指针域 | 主要特点 |
|---|---|---|
| 二叉链表 | lchild、rchild | 找左右孩子方便，找双亲需从根重新搜索；存储密度高，是最常用的结构 |
| 三叉链表 | parent、lchild、rchild | 找双亲、找孩子都方便，但每个结点多一个指针域 |
| 双亲链表 | parent + LRTag | 找双亲方便、找孩子困难；用位置（下标）代替指针 |
| 线索链表 | lchild、rchild 兼作线索，另加 LTag、RTag | 利用空指针域存放遍历序列中的前驱、后继信息，便于线索遍历 |

## 6.4 二叉树的遍历
> 课件页码：P40–P78

本节内容依次为：问题的提出、先左后右的遍历算法、算法的递归描述、中序遍历算法的非递归描述、遍历算法的应用举例。

### 一、问题的提出
> 课件页码：P41–P44

**遍历**：顺着某一条搜索路径巡访二叉树中的结点，使得每个结点均被访问一次，而且仅被访问一次。

“访问”的含义可以很广，如：输出结点的信息等。

- “遍历”是任何类型均有的操作。对线性结构而言，只有一条搜索路径（因为每个结点均只有一个后继），故不需要另加讨论；
- 而二叉树是非线性结构，每个结点有两个后继，则存在如何遍历、即按什么样的搜索路径遍历的问题。

对二叉树而言，可以有三条搜索路径：

1. 先上后下的**按层次遍历**；
2. **先左（子树）后右（子树）**的遍历；
3. 先右（子树）后左（子树）的遍历。

### 二、先左后右的遍历算法
> 课件页码：P45–P48

按“先左后右”的搜索路径，根据访问根结点的先后次序不同，得到三种遍历算法：先（根）序的遍历算法、中（根）序的遍历算法、后（根）序的遍历算法。

**先（根）序的遍历算法**：若二叉树为空树，则空操作；否则，

1. 访问根结点；
2. 先序遍历左子树；
3. 先序遍历右子树。

**中（根）序的遍历算法**：若二叉树为空树，则空操作；否则，

1. 中序遍历左子树；
2. 访问根结点；
3. 中序遍历右子树。

**后（根）序的遍历算法**：若二叉树为空树，则空操作；否则，

1. 后序遍历左子树；
2. 后序遍历右子树；
3. 访问根结点。

三种遍历的区别仅在于“访问根结点”这一步发生在遍历左、右子树之前、之间还是之后。

### 三、算法的递归描述
> 课件页码：P49

以先序遍历为例，递归算法如下（`visit` 为访问结点的函数指针）：

```c
void Preorder(BiTree T, void (*visit)(TElemType& e))
{ // 先序遍历二叉树
    if (T) {
        visit(T->data);             // 访问结点
        Preorder(T->lchild, visit); // 遍历左子树
        Preorder(T->rchild, visit); // 遍历右子树
    }
}
```

三种遍历的递归结构完全相同，只是“访问结点”的位置不同。仿照上面的写法，中序、后序的递归算法为：

```c
void Inorder(BiTree T, void (*visit)(TElemType& e))
{ // 中序遍历二叉树
    if (T) {
        Inorder(T->lchild, visit);  // 遍历左子树
        visit(T->data);             // 访问结点
        Inorder(T->rchild, visit);  // 遍历右子树
    }
}

void Postorder(BiTree T, void (*visit)(TElemType& e))
{ // 后序遍历二叉树
    if (T) {
        Postorder(T->lchild, visit); // 遍历左子树
        Postorder(T->rchild, visit); // 遍历右子树
        visit(T->data);              // 访问结点
    }
}
```

### 四、中序遍历算法的非递归描述
> 课件页码：P50–P51

非递归算法借助栈保存“尚待访问”的结点。中序遍历的非递归实现可以分解为两个算法：

1. `GoFarLeft`：从某结点出发，沿左指针一直下行，把沿途结点压入栈中，返回最左下的结点；
2. `Inorder_I`：先找到最左下结点开始访问；每访问一个结点后，若它有右子树，则对右子树再次执行 `GoFarLeft`，否则从栈中弹出一个结点继续访问；栈空时遍历结束。

```c
BiTNode *GoFarLeft(BiTree T, Stack *S) {
    if (!T) return NULL;
    while (T->lchild) {
        Push(S, T);
        T = T->lchild;
    }
    return T;
}

void Inorder_I(BiTree T, void (*visit)(TElemType& e)) {
    Stack *S;
    t = GoFarLeft(T, S);        // 找到最左下的结点
    while (t) {
        visit(t->data);
        if (t->rchild)
            t = GoFarLeft(t->rchild, S);
        else if (!StackEmpty(S)) // 栈不空时退栈
            t = Pop(S);
        else
            t = NULL;            // 栈空表明遍历结束
    } // while
} // Inorder_I
```

### 五、层次遍历
> 课件页码：P44

按层次遍历属于“先上后下”的搜索路径：自上而下、自左至右逐层访问树中的每个结点（二叉树基本操作中的 `LevelOrderTraverse` 即对应这一遍历）。

实现时借助一个队列：

1. 若树非空，将根结点入队；
2. 队不空时，取队头结点出队并访问；
3. 若该结点有左孩子，则左孩子入队；若有右孩子，则右孩子入队；
4. 重复 2、3，直到队列为空。

```c
void LevelOrder(BiTree T, void (*visit)(TElemType& e)) {
    Queue Q;
    InitQueue(Q);
    if (T) EnQueue(Q, T);           // 根结点入队
    while (!QueueEmpty(Q)) {
        DeQueue(Q, p);              // 队头结点出队
        visit(p->data);
        if (p->lchild) EnQueue(Q, p->lchild);
        if (p->rchild) EnQueue(Q, p->rchild);
    }
} // LevelOrder
```

> 说明：课件在 P44 中把“按层次遍历”列为二叉树的搜索路径之一，并在 P20 的基本操作中给出 `LevelOrderTraverse` 原型，但未展开队列实现的代码；上面按层次遍历的思想整理成队列算法，便于与递归遍历对照。

### 六、遍历算法的应用举例
> 课件页码：P52–P60

遍历是二叉树各种操作的基础。由于先序、中序、后序三种遍历的搜索路径相同、访问时机不同，可以在遍历算法中把“访问结点”的操作换成其它处理，从而得到各种二叉树操作的算法。课件给出以下四类应用：

1. 统计二叉树中叶子结点的个数（先序遍历）；
2. 求二叉树的深度（后序遍历）；
3. 复制二叉树（后序遍历）；
4. 建立二叉树的存储结构。

#### 1. 统计二叉树中叶子结点的个数
> 课件页码：P53–P54

**算法基本思想**：先序（或中序或后序）遍历二叉树，在遍历过程中查找叶子结点并计数。由此需在遍历算法中增添一个“计数”的参数，并将算法中“访问结点”的操作改为：若是叶子，则计数器增 1。

```c
void CountLeaf(BiTree T, int& count) {
    if (T) {
        if ((!T->lchild) && (!T->rchild))
            count++;                // 对叶子结点计数
        CountLeaf(T->lchild, count);
        CountLeaf(T->rchild, count);
    } // if
} // CountLeaf
```

#### 2. 求二叉树的深度
> 课件页码：P55–P56

**算法基本思想**：从二叉树深度的定义可知，二叉树的深度应为其左、右子树深度的最大值加 1。由此需先分别求得左、右子树的深度，算法中“访问结点”的操作为：求得左、右子树深度的最大值，然后加 1。

```c
int Depth(BiTree T) { // 返回二叉树的深度
    if (!T)
        depthval = 0;
    else {
        depthLeft  = Depth(T->lchild);
        depthRight = Depth(T->rchild);
        depthval = 1 + (depthLeft > depthRight ?
                        depthLeft : depthRight);
    }
    return depthval;
}
```

由于先求左、右子树的深度再求整棵树的深度，这一过程正是后序遍历的次序。

#### 3. 复制二叉树
> 课件页码：P57–P60

复制二叉树的基本操作是**生成一个结点**：新结点取原结点的数据，并把已复制好的左、右子树挂到新结点的左、右指针上。

![复制二叉树：由原树结点 T 生成新结点 NEWT，根元素与左右子树一一对应](assets/第06章树和二叉树/p057.jpg)

*图 6-11 复制二叉树：生成新结点、递归复制左、右子树（课件 P57）*

生成一个二叉树结点的算法为（其数据域为 item，左指针域为 lptr，右指针域为 rptr）：

```c
BiTNode *GetTreeNode(TElemType item,
                     BiTNode *lptr, BiTNode *rptr) {
    if (!(T = (BiTNode*)malloc(sizeof(BiTNode))))
        exit(1);
    T->data   = item;
    T->lchild = lptr;
    T->rchild = rptr;
    return T;
}
```

复制二叉树时，先复制左子树和右子树，再生成根结点，因此是**后序遍历**：

```c
BiTNode *CopyTree(BiTNode *T) {
    if (!T) return NULL;
    if (T->lchild)
        newlptr = CopyTree(T->lchild);  // 复制左子树
    else
        newlptr = NULL;
    if (T->rchild)
        newrptr = CopyTree(T->rchild);  // 复制右子树
    else
        newrptr = NULL;
    newT = GetTreeNode(T->data, newlptr, newrptr);
    return newT;
} // CopyTree
```

以一棵 A 为根的二叉树为例，复制过程自底向上进行：先递归复制左、右子树，逐个生成叶子结点，再逐层返回、生成各子树的根结点，最终得到一棵与 T 完全相同的新二叉树（newT）。

#### 4. 建立二叉树的存储结构
> 课件页码：P61–P78

不同的定义方法相应有不同的存储结构的建立算法。课件给出三种建立二叉树存储结构的方法：以字符串形式定义、由表达式建树、由先序和中序序列建树。

##### （1）以字符串的形式定义二叉树
> 课件页码：P62–P64

以字符串的形式按“**根 左子树 右子树**”的次序定义一棵二叉树，并以空白字符（空格）表示空树。例如：

```text
A(B( ,C( , )),D( , ))
```

表示根为 A，左子树为 B（B 的左子树为空、右子树为 C，C 的左右子树均为空），右子树为 D（D 的左右子树均为空）。

- 只含一个根结点的二叉树，以字符串 `A  `（A 后跟空格）表示；
- 空树则只由一个空格组成。

按这一递归定义建立二叉链表的算法如下：

```c
Status CreateBiTree(BiTree &T) {
    scanf(&ch);
    if (ch == ' ')
        T = NULL;
    else {
        if (!(T = (BiTNode *)malloc(sizeof(BiTNode))))
            exit(OVERFLOW);
        T->data = ch;               // 生成根结点
        CreateBiTree(T->lchild);    // 构造左子树
        CreateBiTree(T->rchild);    // 构造右子树
    }
    return OK;
} // CreateBiTree
```

若输入字符串为 `A B □ C □ □ D □ □`（□ 表示空格），则算法执行过程为：读入 A 生成根结点 → 递归建立左子树，读入 B 生成结点 → 建立 B 的左子树时读到空格，置空 → 建立 B 的右子树，读入 C 生成结点，C 的左右子树均读到空格而为空 → 返回建立 A 的右子树，读入 D 生成结点，D 的左右子树均为空。最终得到如下二叉树：

> 课件页码：P65–P74

**由先缀表示式建树**。例如已知表达式的先缀表示式：


它对应的二叉树如下图所示：

该二叉树的特点是：

- **运算符为分支结点**。

由先缀表示式建树的基本操作为：

```text
scanf(&ch);
if ( In(ch, 字母集) )   建叶子结点;
else  { 建根结点;
        递归建左子树;
        递归建右子树;
}
```

**由原表达式建树**。例如已知中缀表达式 `(a+b)×c – d/e`，需先分析表达式和二叉树的关系，再边扫描表达式边建树。下图给出几个表达式与其对应二叉树的关系（运算符为分支结点、操作数为叶子结点）：

![表达式与二叉树的关系示例](assets/第06章树和二叉树/p068.jpg)

*图 6-15 表达式与二叉树的对应关系：a+b、(a+b)×c、a+b×c、(a+b)×c−d/e（课件 P68）*

基本操作为：

```text
scanf(&ch);
if (In(ch, 字母集))  { 建叶子结点; 暂存; }
else  if (In(ch, 运算符集)) {
    和前一个运算符比较优先数;
    若当前的优先数“高”，则暂存;
    否则建子树;
}
```

课件给出的由原表达式建树的算法由主算法 `CrtExptree` 和两个基本操作 `CrtNode`、`CrtSubtree` 组成：`CrtExptree` 用运算符栈 S 和指针栈 PTR 配合扫描表达式，遇到操作数则建叶子结点并入 PTR 栈；遇到运算符则与栈顶运算符比较优先数，优先数高者暂存，否则不断弹出栈顶运算符、用 `CrtSubtree` 建成子树；遇到左括号则入栈，遇到右括号则弹栈建子树直到遇到左括号；扫描结束后弹出 PTR 栈顶即得整棵表达式树。

```c
void CrtExptree(BiTree &T, char exp[]) {
    InitStack(S);  Push(S, '#');
    InitStack(PTR);
    p = exp;  ch = *p;
    while (!(GetTop(S) == '#' && ch == '#')) {
        if (!IN(ch, OP))
            CrtNode(t, ch);     // 建叶子结点并入栈
        else {
            switch (ch) {
            case '(':
                Push(S, ch);  break;
            case ')':
                Pop(S, c);
                while (c != '(') {
                    CrtSubtree(t, c);   // 建二叉树并入栈
                    Pop(S, c);
                }
                break;
            default:
                while (!Gettop(S, c) && precede(c, ch)) {
                    CrtSubtree(t, c);
                    Pop(S, c);
                }
                if (ch != '#') Push(S, ch);
                break;
            } // switch
        }
        if (ch != '#') { p++;  ch = *p; }
    } // while
    Pop(PTR, T);
} // CrtExptree
```

```c
void CrtNode(BiTree& T, char ch) {    // 建叶子结点的算法
    T = (BiTNode*)malloc(sizeof(BiTNode));
    T->data = ch;
    T->lchild = T->rchild = NULL;
    Push(PTR, T);
}

void CrtSubtree(BiTree& T, char c) {  // 建子树的算法
    T = (BiTNode*)malloc(sizeof(BiTNode));
    T->data = c;
    Pop(PTR, rc);  T->rchild = rc;
    Pop(PTR, lc);  T->lchild = lc;
    Push(PTR, T);
}
```

其中 `CrtSubtree` 从指针栈中先弹出的是右子树的根，后弹出的是左子树的根，这与表达式先缀表示式中“左子树在右子树之前”的次序是一致的。

##### （3）由先序和中序序列建树
> 课件页码：P75–P78

仅知二叉树的先序序列，例如 `abcdefg`，**不能唯一确定**一棵二叉树。如果同时已知二叉树的中序序列，例如 `cbdaegf`，则可以唯一确定这棵二叉树。

理由是：

- 二叉树的**先序序列**中，第一个结点一定是根；其余结点依次是左子树的先序序列和右子树的先序序列；
- 二叉树的**中序序列**中，根结点把序列分成左、右两段，左边是左子树的中序序列，右边是右子树的中序序列；
- 由中序序列中根的位置可以求出左子树的结点个数，从而在先序序列中划分出左、右子树的先序序列，然后递归建树。

即：先序序列的“根 + 左子树 + 右子树”与中序序列的“左子树 + 根 + 右子树”一一对应。

按上述思想，可由先序序列 `pre[ps..ps+n-1]` 和中序序列 `ino[is..is+n-1]` 构造二叉链表：

```c
void CrtBT(BiTree& T, char pre[], char ino[],
           int ps, int is, int n) {
    // 已知 pre[ps..ps+n-1] 为二叉树的先序序列，
    // ino[is..is+n-1] 为二叉树的中序序列，本算
    // 法由此两个序列构造二叉链表
    if (n == 0)
        T = NULL;
    else {
        k = Search(ino, pre[ps]);   // 在中序序列中查询
        if (k == -1)
            T = NULL;
        else {
            T = (BiTNode*)malloc(sizeof(BiTNode));
            T->data = pre[ps];
            if (k == is)            // 左子树为空
                T->lchild = NULL;
            else
                CrtBT(T->lchild, pre, ino,
                      ps+1, is, k-is);
            if (k == is+n-1)        // 右子树为空
                T->rchild = NULL;
            else
                CrtBT(T->rchild, pre, ino,
                      ps+1+(k-is), k+1, n-(k-is)-1);
        }
    } // else
} // CrtBT
```

算法中，`k` 为根结点 `pre[ps]` 在中序序列 `ino` 中的位置；`k-is` 为左子树的结点个数，据此可以定出右子树先序序列的起始位置 `ps+1+(k-is)` 和右子树中序序列的起始位置 `k+1`。

**示例**：已知先序序列 `a b c d e f g`、中序序列 `c b d a e g f`，建树过程为：

- 先序首结点 a 是根；中序中 a 左边 `c b d` 是左子树的中序序列，右边 `e g f` 是右子树的中序序列；
- 左子树先序为 `b c d`、中序为 `c b d`：根为 b，b 的左孩子为 c、右孩子为 d；
- 右子树先序为 `e f g`、中序为 `e g f`：根为 e，e 无左孩子；其右子树先序为 `f g`、中序为 `g f`，根为 f，f 的左孩子为 g、无右孩子。

最终得到的二叉树为：根 a，左孩子 b（b 的左孩子 c、右孩子 d），右孩子 e（e 无左孩子，右孩子 f，f 的左孩子 g）。

## 6.5 线索二叉树
> 课件页码：P79–P91

### 一、何谓线索二叉树
> 课件页码：P80–P83

遍历二叉树的结果，是求得结点的一个线性序列。例如，对课件 P80 中的二叉树：

![线索二叉树的例子：同一棵树的三种遍历序列](assets/第06章树和二叉树/p080.jpg)

*图 6-16 线索二叉树的例子：先序、中序、后序序列（课件 P80）*

```text
先序序列：A B C D E F G H K
中序序列：B D C A H G K F E
后序序列：D C B H K G F E A
```

把指向该线性序列中“前驱”和“后继”的指针，称作**线索**；与其相应的二叉树，称作**线索二叉树**；包含“线索”的存储结构，称作**线索链表**。

线索链表是在二叉链表的基础上，对结点的空指针域加以利用：

- 若该结点的左子树不空，则 Lchild 域的指针指向其左子树，且左标志域的值为 `Link`（指针）；
- 否则，Lchild 域的指针指向其“前驱”，且左标志的值为 `Thread`（线索）；
- 若该结点的右子树不空，则 rchild 域的指针指向其右子树，且右标志域的值为 `Link`（指针）；
- 否则，rchild 域的指针指向其“后继”，且右标志的值为 `Thread`（线索）。

如此定义的二叉树的存储结构称作“线索链表”。按遍历次序的不同，可有先序线索二叉树、中序线索二叉树和后序线索二叉树；课件重点讨论**中序线索化**。

### 二、线索链表的类型描述
> 课件页码：P84

在二叉链表的结点中增加两个标志域 `LTag`、`RTag`：

```c
typedef enum { Link, Thread } PointerThr;
    // Link==0:指针，Thread==1:线索

typedef struct BiThrNode {
    TElemType         data;
    struct BiThrNode *lchild, *rchild;  // 左右指针
    PointerThr        LTag, RTag;       // 左右标志
} BiThrNode, *BiThrTree;
```

### 三、线索链表的遍历算法
> 课件页码：P85–P87

由于在线索链表中添加了遍历中得到的“前驱”和“后继”的信息，从而简化了遍历算法。线索链表遍历的一般形式为：

```c
for (p = firstNode(T); p; p = Succ(p))
    Visit(p);
```

只要给出“求第一个结点”和“求后继”两个操作，就可以沿线索依次访问全部结点。

对**中序线索化链表**，这两个操作是：

- **中序遍历的第一个结点**：左子树上处于“最左下”（没有左子树）的结点；
- **在中序线索化链表中结点的后继**：若无右子树，则为后继线索所指结点；否则为对其右子树进行中序遍历时访问的第一个结点（即右子树中最左下的结点）。

据此得到中序线索链表的遍历算法（T 为头结点，其 lchild 指向根结点）：

```c
void InOrderTraverse_Thr(BiThrTree T,
                         void (*Visit)(TElemType e)) {
    p = T->lchild;          // p 指向根结点
    while (p != T) {        // 空树或遍历结束时，p==T
        while (p->LTag == Link)
            p = p->lchild;  // 第一个结点
        Visit(p->data);     // 访问其左子树为空的结点
        while (p->RTag == Thread && p->rchild != T) {
            p = p->rchild;
            Visit(p->data); // 访问后继结点
        }
        p = p->rchild;      // p 进至其右子树根
    }
} // InOrderTraverse_Thr
```

### 四、如何建立线索链表
> 课件页码：P88–P91

建立线索链表（线索化）的实质是：在中序遍历过程中修改结点的左、右指针域，以保存当前访问结点的“前驱”和“后继”信息。遍历过程中附设指针 `pre`，并始终保持指针 `pre` 指向当前访问的、指针 `p` 所指结点的前驱。

**中序线索化的递归算法**：

```c
void InThreading(BiThrTree p) {
    if (p) {    // 对以 p 为根的非空二叉树进行线索化
        InThreading(p->lchild);     // 左子树线索化
        if (!p->lchild) {           // 建前驱线索
            p->LTag = Thread;
            p->lchild = pre;
        }
        if (!pre->rchild) {         // 建后继线索
            pre->RTag = Thread;
            pre->rchild = p;
        }
        pre = p;                    // 保持 pre 指向 p 的前驱
        InThreading(p->rchild);     // 右子树线索化
    } // if
} // InThreading
```

为了让线索链表能像线性表一样找到第一个结点和最后一个结点，并便于判断遍历结束，通常在线索链表上增加一个**头结点**：头结点的 lchild 指向根结点，rchild 指向中序遍历的最后一个结点；同时令中序序列第一个结点的 lchild 线索和最后一个结点的 rchild 线索都指向头结点。构建中序线索链表的算法为：

```c
Status InOrderThreading(BiThrTree &Thrt,
                        BiThrTree T) { // 构建中序线索链表
    if (!(Thrt = (BiThrTree)malloc(sizeof(BiThrNode))))
        exit(OVERFLOW);
    Thrt->LTag = Link;
    Thrt->RTag = Thread;
    Thrt->rchild = Thrt;            // 添加头结点
    if (!T)
        Thrt->lchild = Thrt;
    else {
        Thrt->lchild = T;
        pre = Thrt;
        InThreading(T);
        pre->rchild = Thrt;         // 处理最后一个结点
        pre->RTag = Thread;
        Thrt->rchild = pre;
    }
    return OK;
} // InOrderThreading
```

### 四、森林和二叉树的对应关系
> 课件页码：P103–P106

设森林

```text
F = ( T1, T2, …, Tn );
T1 = ( root, t11, t12, …, t1m );
```

二叉树

```text
B = ( LBT, Node(root), RBT );
```

**由森林转换成二叉树的转换规则**为：

- 若 F = Φ，则 B = Φ；
- 否则：
    - 由 ROOT( T1 ) 对应得到 Node(root)；
    - 由 ( t11, t12, …, t1m ) 对应得到 LBT；
    - 由 ( T2, T3, …, Tn ) 对应得到 RBT。

即：森林中第一棵树的根作为二叉树的根；第一棵树的子树森林转换为二叉树的左子树；其余树构成的森林转换为二叉树的右子树。

**由二叉树转换为森林的转换规则**为：

- 若 B = Φ，则 F = Φ；
- 否则：
    - 由 Node(root) 对应得到 ROOT( T1 )；
    - 由 LBT 对应得到 ( t11, t12, …, t1m )；
    - 由 RBT 对应得到 ( T2, T3, …, Tn )。

上述转换过程可逆，因此树和森林都可以唯一地转换成二叉树。由此，树的各种操作均可对应二叉树的操作来完成。

![树转换为二叉树后，左指针指向孩子、右指针指向兄弟](assets/第06章树和二叉树/p106.jpg)

*图 6-21 树对应的二叉树中“左是孩子，右是兄弟”（课件 P106）*

应当注意的是，和树对应的二叉树，其左、右子树的概念已改变为：**左是孩子，右是兄弟**。

## 6.7 树和森林的遍历

### 一、树的遍历
> 课件页码：P108–P110

树的遍历可有三条搜索路径：

- **按层次遍历**：若树不空，则自上而下自左至右访问树中每个结点；
- **先根（次序）遍历**：若树不空，则先访问根结点，然后依次先根遍历各棵子树；
- **后根（次序）遍历**：若树不空，则先依次后根遍历各棵子树，然后访问根结点。

### 二、森林的遍历
> 课件页码：P111–P114

森林由三部分构成：

1. 森林中第一棵树的根结点；
2. 森林中第一棵树的子树森林；
3. 森林中其它树构成的森林。

**1. 先序遍历森林**：若森林不空，则

1. 访问森林中第一棵树的根结点；
2. 先序遍历森林中第一棵树的子树森林；
3. 先序遍历森林中（除第一棵树之外）其余树构成的森林。

即：依次从左至右对森林中的每一棵树进行**先根遍历**。

**2. 中序遍历森林**：若森林不空，则

1. 中序遍历森林中第一棵树的子树森林；
2. 访问森林中第一棵树的根结点；
3. 中序遍历森林中（除第一棵树之外）其余树构成的森林。

即：依次从左至右对森林中的每一棵树进行**后根遍历**。

#### 1. 求树的深度
> 课件页码：P116

以孩子兄弟链表存储时，树中某结点的“子树森林”的深度可由 `firstchild` 递归求得，而其“兄弟森林”的深度可由 `nextsibling` 递归求得，二者取大值即得树的深度。

```c
int TreeDepth(CSTree T) {
    if (!T)
        return 0;
    else {
        h1 = TreeDepth(T->firstchild);   // 子树森林的深度
        h2 = TreeDepth(T->nextsibling);  // 兄弟森林的深度
    }
    return (max(h1+1, h2));
} // TreeDepth
```

## 6.8 哈夫曼树与哈夫曼编码
> 课件页码：P124–P133

### 一、最优树的定义
> 课件页码：P125–P127

- **结点的路径长度**：从根结点到该结点的路径上分支的数目。
- **树的路径长度**：树中每个结点的路径长度之和。
- **树的带权路径长度**：树中所有叶子结点的带权路径长度之和，记为

```text
WPL(T) = Σ wₖ · lₖ   （对所有叶子结点）
```

其中 wₖ 为第 k 个叶子结点的权值，lₖ 为该叶子结点到根的路径长度。

**最优树**：在所有含 n 个叶子结点、并带相同权值的 m 叉树中，必存在一棵其带权路径长度取最小值的树，称为“最优树”。

例如，权值为 7、5、2、4、9 的五片叶子构成的两棵二叉树：

![两棵二叉树的带权路径长度对比](assets/第06章树和二叉树/p127.jpg)

*图 6-26 两棵二叉树的 WPL 比较：分别为 60 与 89（课件 P127）*

```text
WPL(T) = 7×2 + 5×2 + 2×3 + 4×3 + 9×2 = 60
WPL(T) = 7×4 + 9×4 + 5×3 + 4×2 + 2×1 = 89
```

前者叶子结点的平均深度更小、带权路径长度更短，因而更“优”；最优树就是使 WPL 达到最小的那棵树。

### 二、如何构造最优树（哈夫曼算法）
> 课件页码：P128–P131

根据给定的 n 个权值 {w1, w2, …, wn}，构造 n 棵二叉树的集合 F = {T1, T2, …, Tn}，其中每棵二叉树中均只含一个带权值为 wi 的根结点，其左、右子树为空树。

以二叉树为例，赫夫曼算法的步骤如下：

1. 构造 n 棵只含一个带权根结点的二叉树，组成集合 F；
2. 在 F 中选取其根结点的权值为**最小**的两棵二叉树，分别作为**左、右子树**构造一棵新的二叉树，并置这棵新的二叉树根结点的权值为其左、右子树根结点的权值之和；
3. 从 F 中删去这两棵树，同时加入刚生成的新树；
4. 重复 (2) 和 (3) 两步，直至 F 中只含一棵树为止。

由此得到的树即为最优树（哈夫曼树），其所有叶子结点对应给定的 n 个权值。

### 三、前缀编码
> 课件页码：P132–P133

**前缀编码**：指的是任何一个字符的编码都不是同一字符集中另一个字符的编码的前缀。

利用赫夫曼树可以构造一种不等长的二进制编码，并且构造所得的赫夫曼编码是一种**最优前缀编码**，即使所传电文的总长度最短。

构造方法：以 n 个字符的权值（如出现频率）作为叶子权值构造哈夫曼树，然后对每个叶子结点，从根到该叶子的路径上，规定指向左孩子的分支为 0、指向右孩子的分支为 1，则从根到叶子途经的 0/1 序列即为该字符的编码。

对上例权值 W = {5, 6, 2, 9, 7} 的哈夫曼树，可得编码：

| 权值 | 6 | 7 | 9 | 5 | 2 |
|---|---|---|---|---|---|
| 哈夫曼编码 | 00 | 01 | 10 | 110 | 111 |

因为每个字符的编码都是哈夫曼树中一片叶子到根的路径，所以任一编码都不可能是另一编码的前缀（前缀关系只可能出现在祖先与子孙之间，而字符都对应叶子），从而解码时不会产生歧义；同时由于哈夫曼树的带权路径长度最小，所传电文的总长度也最短。

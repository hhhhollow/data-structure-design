## 导言 线性结构的基本特征

> 课件页码：P1–P2

线性结构的基本特征为：

1. 集合中必存在唯一的一个“第一元素”；
2. 集合中必存在唯一的一个“最后元素”；
3. 除最后元素之外，均有唯一的后继；
4. 除第一元素之外，均有唯一的前驱。

线性结构是**一个数据元素的有序（次序）集**，而线性表是一种最简单的线性结构。

### 一、抽象数据类型线性表的定义

> 课件页码：P4

抽象数据类型线性表的定义如下：

```text
ADT List {
    数据对象：D = { ai | ai ∈ ElemSet, i = 1, 2, ..., n,  n ≥ 0 }
    数据关系：R1 = { <ai-1, ai> | ai-1, ai ∈ D,  i = 2, ..., n }
    基本操作：
        InitList(&L)                                     // 结构初始化操作
        DestroyList(&L)                                  // 结构销毁操作
        ListEmpty(L)          ListLength(L)
        PriorElem(L, cur_e, &pre_e)   NextElem(L, cur_e, &next_e)
        GetElem(L, i, &e)     LocateElem(L, e, compare())
        ListTraverse(L, visit())                         // 引用型操作
        ClearList(&L)         PutElem(&L, i, &e)
        ListInsert(&L, i, e)  ListDelete(&L, i, &e)      // 加工型操作
} ADT List
```

几点说明：

- 数据对象 D 中的元素同属于某个数据元素集合 ElemSet；
- 称 n 为线性表的**表长**，称 n = 0 时的线性表为**空表**；
- 数据关系 R1 由相邻数据元素之间的有序对构成，即每一对相邻元素之间都存在次序关系；
- 设线性表为 (a1, a2, …, ai, …, an)，则称 i 为 ai 在线性表中的**位序**。

### 二、基本操作及其定义

> 课件页码：P5–P20

基本操作按作用分为四类：

| 类别 | 操作 | 作用 |
| --- | --- | --- |
| 结构初始化操作 | InitList(&L) | 构造一个空的线性表 |
| 结构销毁操作 | DestroyList(&L) | 销毁已存在的线性表 |
| 引用型操作 | ListEmpty、ListLength、PriorElem、NextElem、GetElem、LocateElem、ListTraverse | 取表中的信息：判空、求长、求前驱/后继、取某个元素、定位、遍历 |
| 加工型操作 | ClearList、PutElem、ListInsert、ListDelete | 改变线性表本身：置空、赋值、插入、删除 |

各基本操作的定义如下表（课件 P6–P20）：

| 操作 | 初始条件 | 操作结果 |
| --- | --- | --- |
| `InitList( &L )`（初始化操作） | 无 | 构造一个空的线性表 L |
| `DestroyList( &L )`（结构销毁操作） | 线性表 L 已存在 | 销毁线性表 L |
| `ListEmpty( L )`（线性表判空） | 线性表 L 已存在 | 若 L 为空表，则返回 TRUE，否则 FALSE |
| `ListLength( L )`（求线性表的长度） | 线性表 L 已存在 | 返回 L 中元素个数 |
| `PriorElem( L, cur_e, &pre_e )`（求数据元素的前驱） | 线性表 L 已存在 | 若 cur_e 是 L 的元素，但不是第一个，则用 pre_e 返回它的前驱；否则操作失败，pre_e 无定义 |
| `NextElem( L, cur_e, &next_e )`（求数据元素的后继） | 线性表 L 已存在 | 若 cur_e 是 L 的元素，但不是最后一个，则用 next_e 返回它的后继；否则操作失败，next_e 无定义 |
| `GetElem( L, i, &e )`（求线性表中某个数据元素） | 线性表 L 已存在，且 1 ≤ i ≤ LengthList(L) | 用 e 返回 L 中第 i 个元素的值 |
| `LocateElem( L, e, compare( ) )`（定位函数） | 线性表 L 已存在，e 为给定值，compare( ) 是元素判定函数 | 返回 L 中第 1 个与 e 满足关系 compare( ) 的元素的位序；若这样的元素不存在，则返回值为 0 |
| `ListTraverse( L, visit( ) )`（遍历线性表） | 线性表 L 已存在，visit( ) 为某个访问函数 | 依次对 L 的每个元素调用函数 visit( )；一旦 visit( ) 失败，则操作失败 |
| `ClearList( &L )`（线性表置空） | 线性表 L 已存在 | 将 L 重置为空表 |
| `PutElem( &L, i, &e )`（改变数据元素的值） | 线性表 L 已存在，且 1 ≤ i ≤ LengthList(L) | L 中第 i 个元素赋值同 e 的值 |
| `ListInsert( &L, i, e )`（插入数据元素） | 线性表 L 已存在，且 1 ≤ i ≤ LengthList(L)+1 | 在 L 的第 i 个元素之前插入新的元素 e，L 的长度增 1 |
| `ListDelete( &L, i, &e )`（删除数据元素） | 线性表 L 已存在且非空，1 ≤ i ≤ LengthList(L) | 删除 L 的第 i 个元素，并用 e 返回其值，L 的长度减 1 |

### 三、应用举例

> 课件页码：P21–P36

利用上述定义的线性表，可以实现其他更复杂的操作。课件给出的三个例子是：例 2-1、例 2-2、例 2-3（课件 P21）。

#### 例 2-1　求集合的并集 A = A ∪ B

> 课件页码：P22–P25

**问题**：假设有两个集合 A 和 B，分别用两个线性表 LA 和 LB 表示，即线性表中的数据元素即为集合中的成员。现要求一个新的集合 A = A ∪ B。

**演绎**：上述问题可演绎为——要求对线性表作如下操作：扩大线性表 LA，将存在于线性表 LB 中而不存在于线性表 LA 中的数据元素插入到线性表 LA 中去。

**操作步骤**：

1. 从线性表 LB 中依次察看每个数据元素：`GetElem(LB, i) → e`；
2. 依值在线性表 LA 中进行查访：`LocateElem(LA, e, equal( ))`；
3. 若不存在，则插入之：`ListInsert(LA, n+1, e)`。

**算法**：

```c
void union(List &La, List Lb) {
    La_len = ListLength(La);    // 求线性表的长度
    Lb_len = ListLength(Lb);
    for (i = 1;  i <= Lb_len;  i++) {
        GetElem(Lb, i, e);    // 取 Lb 中第 i 个数据元素赋给 e
        if (!LocateElem(La, e, equal( )))
            ListInsert(La, ++La_len, e);
            // La 中不存在和 e 相同的数据元素，则插入之
    }
} // union
```

#### 例 2-2　构造纯集合

> 课件页码：P26–P31

**问题**：已知一个非纯集合 B，试构造一个纯集合 A，使 A 中只包含 B 中所有值各不相同的数据元素。仍选用线性表表示集合。

![集合 B 与集合 A](assets/第02章线性表/p027.jpg)
*图 2-2 从集合 B 取出物件放入集合 A，要求集合 A 中同样物件不能有两件以上（课件 P27）*

从集合 B 取出物件放入集合 A，要求集合 A 中同样物件不能有两件以上，因此算法的策略应该和例 2-1 相同。对应算法为：

```c
void union(List &La, List Lb) {
    InitList(La);    // 构造(空的)线性表 LA
    La_len = ListLength(La);    Lb_len = ListLength(Lb);
    for (i = 1;  i <= Lb_len;  i++) {
        GetElem(Lb, i, e);    // 取 Lb 中第 i 个数据元素赋给 e
        if (!LocateElem(La, e, equal( )))
            ListInsert(La, ++La_len, e);
            // La 中不存在和 e 相同的数据元素，则插入之
    }
} // union
```

**改变结构：用有序表表示集合**

若线性表中的数据元素相互之间可以比较，并且数据元素在线性表中依值非递减或非递增有序排列（ai ≥ ai−1 或 ai ≤ ai−1，i = 2, 3, …, n），则称该线性表为**有序表**（Ordered List）。试改变结构，以有序表表示集合。

例如：（2，3，3，5，6，6，6，8，12）

- 对集合 B 而言，值相同的数据元素必定相邻；
- 对集合 A 而言，数据元素依值从小至大的顺序插入。

因此，数据结构改变了，解决问题的策略也相应要改变：只需把当前元素与刚插入到 A 中的上一个元素 en 比较即可。对应算法为：

```c
void purge(List &La, List Lb) {
    InitList(LA);    La_len = ListLength(La);
    Lb_len = ListLength(Lb);    // 求线性表的长度
    for (i = 1;  i <= Lb_len;  i++) {
        GetElem(Lb, i, e);    // 取 Lb 中第 i 个数据元素赋给 e
        if (ListEmpty(La) || !equal (en, e)) {
            ListInsert(La, ++La_len, e);
            en = e;
        }   // La 中不存在和 e 相同的数据元素，则插入之
    }
} // purge
```

#### 例 2-3　归并两个有序表

> 课件页码：P32–P36

> 注：课件 P32、P33 两页无文字内容（配图渲染亦为空白），题面与图示未能保留；从 P34 起可看出本例的任务是：将两个非递减的有序表 La 和 Lb 归并为一个新的有序表 Lc。

**归并思路**：

- 设 i、j 分别为 La、Lb 的当前位序，k 为 Lc 的长度，初始时 i = j = 1，k = 0；
- 逐次比较两表的当前元素 ai 与 bj，将较小者插入 Lc 的尾部，相应位序后移；
- 当其中一个表的元素取完后，把另一个表的剩余元素依次插入 Lc。

三个基本操作（课件 P34）：

```c
// La 和 Lb 均非空，i = j = 1, k = 0
GetElem(La, i, ai);
GetElem(Lb, j, bj);
if (ai <= bj) {  // 将 ai 插入到 Lc 中
    ListInsert(Lc, ++k, ai);  ++i;
}
else {   // 将 bj 插入到 Lc 中
    ListInsert(Lc, ++k, bj);  ++j;
}
```

**完整算法**（课件 P35–P36）：

```c
void MergeList(List La, List Lb, List &Lc) {
    // 本算法将非递减的有序表 La 和 Lb 归并为 Lc
    InitList(Lc);    // 构造空的线性表 Lc
    i = j = 1;    k = 0;
    La_len = ListLength(La);
    Lb_len = ListLength(Lb);
    while ((i <= La_len) && (j <= Lb_len)) {
        // La 和 Lb 均不空
        GetElem(La, i, ai);
        GetElem(Lb, j, bj);
        if (ai <= bj) {  // 将 ai 插入到 Lc 中
            ListInsert(Lc, ++k, ai);  ++i;
        }
        else {   // 将 bj 插入到 Lc 中
            ListInsert(Lc, ++k, bj);  ++j;
        }
    }
    while (i <= La_len) {    // 当 La 不空时
        GetElem(La, i++, ai);
        ListInsert(Lc, ++k, ai);
    }   // 插入 La 表中剩余元素
    while (j <= Lb_len) {    // 当 Lb 不空时
        GetElem(Lb, j++, bj);
        ListInsert(Lc, ++k, bj);
    }   // 插入 Lb 表中剩余元素
} // MergeList
```

控制结构为三个并列的 while 循环，基本操作是 GetElem 和 ListInsert；当线性表以顺序映像实现时，算法时间复杂度为 O(ListLength(La)+ListLength(Lb))（课件 P80，详见 2.3 节）。

### 一、顺序映象与地址计算

> 课件页码：P38–P40

**顺序映象**：以 x 的存储位置和 y 的存储位置之间的某种关系表示逻辑关系 <x, y>。最简单的一种顺序映象方法是：令 y 的存储位置和 x 的存储位置相邻。

**顺序映象的实现**：用一组地址连续的存储单元依次存放线性表中的数据元素。

```text
        a1      a2      …     ai-1     ai     …     an
       ↑
   线性表的起始地址，称作线性表的基地址
```

以“存储位置相邻”表示有序对 <ai−1，ai>，即 `LOC(ai) = LOC(ai-1) + C`（C 为一个数据元素所占存储量）。因此所有数据元素的存储位置均取决于第一个数据元素的存储位置：

```text
LOC(ai) = LOC(ai-1) + C          // C：一个数据元素所占存储量
LOC(ai) = LOC(a1) + (i-1) × C    // LOC(a1) 即基地址
```

由此可见：只要知道基地址和每个元素所占存储量，就可以直接算出任一位序元素的存储位置，即顺序映象支持按位序直接存取（随机存取）。

### 二、顺序映像的 C 语言描述

> 课件页码：P41

```c
#define  LIST_INIT_SIZE   80
                 // 线性表存储空间的初始分配量
#define  LISTINCREMENT    10
                 // 线性表存储空间的分配增量

typedef  struct {
    ElemType *elem;        // 存储空间基址
    int      length;       // 当前长度
    int      listsize;     // 当前分配的存储容量
                           // (以 sizeof(ElemType) 为单位)
} SqList;   // 俗称 顺序表
```

顺序表用三个域描述：存储空间基址 elem、当前长度 length、当前分配的存储容量 listsize。当表中元素个数超过 listsize 时，需要按 LISTINCREMENT 追加分配空间。

### 三、顺序表上基本操作的实现

#### 1. InitList_Sq——构造一个空的线性表

> 课件页码：P43

```c
Status InitList_Sq( SqList& L ) {
    // 构造一个空的线性表
    L.elem = (ElemType*) malloc (LIST_INIT_SIZE * sizeof (ElemType));
    if (!L.elem) exit(OVERFLOW);
    L.length = 0;
    L.listsize = LIST_INIT_SIZE;
    return OK;
} // InitList_Sq
```

算法时间复杂度：O(1)。

#### 2. LocateElem_Sq——按判定条件查找

> 课件页码：P44–P45

例如：顺序表 (23, 75, 41, 38, 54, 62, 17)，令 e = 38。查找时令指针 p 从 L.elem（第 1 个元素）开始逐个后移，每移一次比较一次，直到 compare(*p, e) 为真为止；本例中 e = 38 是第 4 个元素，p 移动 4 次后即可确定其位序。可见，基本操作是：**将顺序表中的元素逐个和给定值 e 相比较**。

```c
int LocateElem_Sq(SqList L, ElemType e,
        Status (*compare)(ElemType, ElemType)) {
    // 在顺序表中查询第一个满足判定条件的数据元素，
    // 若存在，则返回它的位序，否则返回 0
    i = 1;           // i 的初值为第 1 元素的位序
    p = L.elem;      // p 的初值为第 1 元素的存储位置
    while (i <= L.length && !(*compare)(*p++, e))  ++i;
    if (i <= L.length)  return i;
    else  return 0;
} // LocateElem_Sq
```

算法的时间复杂度为：O(ListLength(L))。

#### 3. ListInsert_Sq——插入数据元素

> 课件页码：P46–P51

**先分析插入元素时线性表的逻辑结构发生什么变化**：

```text
(a1, …, ai-1, ai, …, an)   改变为   (a1, …, ai-1, e, ai, …, an)
```

- 有序对 <ai−1, ai> 改变为 <ai−1, e> 和 <e, ai>；
- 表的长度增加 1。

**插入步骤**：

1. 检查插入位置是否合法（1 ≤ i ≤ L.length+1），不合法返回 ERROR；
2. 若当前存储空间已满（L.length ≥ L.listsize），用 realloc 增加分配；
3. 将第 i 个元素及其后的所有元素依次右移一个位置后写入 e，表长增 1。

```c
Status ListInsert_Sq(SqList &L, int i, ElemType e) {
    // 在顺序表 L 的第 i 个元素之前插入新的元素 e，
    // i 的合法范围为  1≤i≤L.length+1
    if (i < 1 || i > L.length+1) return ERROR;
                                // 插入位置不合法
    if (L.length >= L.listsize) {
                          // 当前存储空间已满，增加分配
        newbase = (ElemType *)realloc(L.elem,
             (L.listsize+LISTINCREMENT)*sizeof (ElemType));
        if (!newbase) exit(OVERFLOW);
                           // 存储分配失败
        L.elem = newbase;                // 新基址
        L.listsize += LISTINCREMENT;     // 增加存储容量
    }
    q = &(L.elem[i-1]);                 // q 指示插入位置
    for (p = &(L.elem[L.length-1]); p >= q;  --p)
         *(p+1) = *p;       // 插入位置及之后的元素右移
    *q = e;       // 插入 e
    ++L.length;   // 表长增 1
    return OK;
} // ListInsert_Sq
```

算法时间复杂度为：O(ListLength(L))。

**示例**：ListInsert_Sq(L, 5, 66)，L 的元素为 (21, 18, 30, 75, 42, 56, 87)。q 指向第 5 个位置，p 从表尾元素 87 开始向前扫描，把 87、56、42 依次右移一位，然后 *q = 66，得到 (21, 18, 30, 75, 66, 42, 56, 87)，表长由 7 增为 8。

**考虑移动元素的平均情况**：假设在第 i 个元素之前插入的概率为 p_i，则在长度为 n 的线性表中插入一个元素所需移动元素次数的期望值为：

```text
E_is = Σ(i=1..n+1) p_i × (n - i + 1)
```

若假定在线性表中任何一个位置上进行插入的概率都是相等的，则移动元素的期望值为：

```text
E_is = (1/(n+1)) × Σ(i=1..n+1) (n - i + 1) = n/2
```

#### 4. ListDelete_Sq——删除数据元素

> 课件页码：P52–P56

**先分析删除元素时线性表的逻辑结构发生什么变化**：

```text
(a1, …, ai-1, ai, ai+1, …, an)   改变为   (a1, …, ai-1, ai+1, …, an)
```

- 有序对 <ai−1, ai> 和 <ai, ai+1> 改变为 <ai−1, ai+1>；
- 表的长度减少 1。

**删除步骤**：

1. 检查删除位置是否合法（1 ≤ i ≤ L.length），不合法返回 ERROR；
2. 用 e 返回被删除元素的值，再将被删除元素之后的所有元素依次左移一个位置；
3. 表长减 1。

```c
Status ListDelete_Sq
        (SqList &L, int i, ElemType &e) {
    if ((i < 1) || (i > L.length))  return ERROR;
                                // 删除位置不合法
    p = &(L.elem[i-1]);      // p 为被删除元素的位置
    e = *p;                  // 被删除元素的值赋给 e
    q = L.elem+L.length-1;   // 表尾元素的位置
    for (++p; p <= q; ++p)  *(p-1) = *p;
                            // 被删除元素之后的元素左移
    --L.length;             // 表长减 1
    return OK;
} // ListDelete_Sq
```

算法时间复杂度为：O(ListLength(L))。

**示例**：ListDelete_Sq(L, 5, e)，L 的元素为 (21, 18, 30, 75, 42, 56, 87)。p 指向第 5 个元素 42，e 取得 42，q 指向表尾 87；随后 56、87 依次左移一位，得到 (21, 18, 30, 75, 56, 87)，表长减 1。

**考虑移动元素的平均情况**：假设删除第 i 个元素的概率为 q_i，则在长度为 n 的线性表中删除一个元素所需移动元素次数的期望值为：

```text
E_dl = Σ(i=1..n) q_i × (n - i)
```

若假定在线性表中任何一个位置上进行删除的概率都是相等的，则移动元素的期望值为：

```text
E_dl = (1/n) × Σ(i=1..n) (n - i) = (n-1)/2
```

### 一、单链表

> 课件页码：P59–P60

单链表用**一组地址任意的存储单元**存放线性表中的数据元素。

- 元素（数据元素的映象）+ 指针（指示后继元素存储位置）= **结点**（表示数据元素或数据元素的映象）；
- 以“结点的序列”表示线性表，称作**链表**。

以线性表中第一个数据元素 a1 的存储地址作为线性表的地址，称作线性表的**头指针**。有时为了操作方便，在第一个结点之前虚加一个“**头结点**”，以指向头结点的指针为链表的头指针。

```text
L ──→ [头结点| →] ──→ [a1| →] ──→ [a2| →] ──→ … ──→ [an| ∧]
                                                         空指针
```

线性表为空表时，头结点的指针域为空。

#### 1. GetElem_L——取第 i 个数据元素

> 课件页码：P63–P65

在单链表 (21, 18, 30, 75, 42, 56) 中取第 3 个元素时：p 从第一个结点开始，令 j = 1，p 每后移一次 j 加 1，依次经过 21（j = 1）、18（j = 2）、30（j = 3），此时 p 所指结点即为所求。

因此，查找第 i 个数据元素的基本操作为：**移动指针，比较 j 和 i**。单链表是一种**顺序存取**的结构，为找第 i 个数据元素，必须先找到第 i−1 个数据元素；令指针 p 始终指向线性表中第 j 个数据元素。

```c
Status GetElem_L(LinkList L, int i, ElemType &e) {
    // L 是带头结点的链表的头指针，以 e 返回第 i 个元素
    p = L->next;   j = 1;   // p 指向第一个结点，j 为计数器
    while (p && j<i)  { p = p->next;  ++j;  }
        // 顺指针向后查找，直到 p 指向第 i 个元素
        // 或 p 为空
    if ( !p || j>i )
        return ERROR;      //  第 i 个元素不存在
    e = p->data;                 //  取得第 i 个元素
    return OK;
} // GetElem_L
```

算法时间复杂度为：O(ListLength(L))。

#### 2. ListInsert_L——插入数据元素

> 课件页码：P66–P69

插入时，有序对 <ai−1, ai> 改变为 <ai−1, e> 和 <e, ai>：

```text
… ──→ [ai-1| →] ──→ [e| →] ──→ [ai| →] ──→ …
```

因此，在单链表中第 i 个结点之前进行插入的基本操作为：**找到线性表中第 i−1 个结点，然后修改其指向后继的指针**。可见，在链表中插入结点只需要修改指针；但同时，若要在第 i 个结点之前插入元素，修改的是第 i−1 个结点的指针。

```c
Status ListInsert_L(LinkList L, int i, ElemType e) {
     // L 为带头结点的单链表的头指针，本算法
     // 在链表中第 i 个结点之前插入新的元素 e
    p = L;    j = 0;
    while (p && j < i-1)
         { p = p->next;  ++j; }   // 寻找第 i-1 个结点
    if (!p || j > i-1)
          return ERROR;      // i 大于表长或者小于 1
    s = (LinkList) malloc ( sizeof (LNode));
                               // 生成新结点
    s->data = e;
    s->next = p->next;      p->next = s; // 插入
    return OK;
} // ListInsert_L
```

算法的时间复杂度为：O(ListLength(L))。

#### 3. ListDelete_L——删除数据元素

> 课件页码：P70–P72

删除时，有序对 <ai−1, ai> 和 <ai, ai+1> 改变为 <ai−1, ai+1>：

```text
… ──→ [ai-1| →] ──→ [ai| →] ──→ [ai+1| →] ──→ …
           └──────── 改指 ────────┘
```

在单链表中删除第 i 个结点的基本操作为：**找到线性表中第 i−1 个结点，修改其指向后继的指针**，即 `q = p->next;  p->next = q->next;  e = q->data;  free(q);`。

```c
Status ListDelete_L(LinkList L, int i, ElemType &e) {
   // 删除以 L 为头指针(带头结点)的单链表中第 i 个结点
    p = L;    j = 0;
    while (p->next && j < i-1) {  p = p->next;   ++j; }
                           // 寻找第 i 个结点，并令 p 指向其前趋
    if  (!(p->next) || j > i-1)
        return ERROR;  // 删除位置不合理
    q = p->next;   p->next = q->next;  // 删除并释放结点
    e = q->data;   free(q);
    return OK;
} // ListDelete_L
```

算法的时间复杂度为：O(ListLength(L))。

#### 4. ClearList——将单链表置为空表

> 课件页码：P73

```c
void ClearList(&L) {
   // 将单链表重新置为一个空表
    while (L->next) {
        p=L->next;    L->next=p->next;
        free(p);
    }
} // ClearList
```

算法时间复杂度：O(ListLength(L))。

#### 5. CreateList_L——逆位序建立单链表

> 课件页码：P74–P76

如何从线性表得到单链表？链表是一个动态的结构，它不需要预先分配空间，因此**生成链表的过程是一个结点“逐个插入”的过程**。

例如：逆位序输入 n 个数据元素的值，建立带头结点的单链表。操作步骤：

1. 建立一个“空表”；
2. 输入数据元素 an，建立结点并插入；
3. 输入数据元素 an−1，建立结点并插入；
4. 依次类推，直至输入 a1 为止。

```c
void CreateList_L(LinkList &L, int n) {
    // 逆序输入 n 个数据元素，建立带头结点的单链表
    L = (LinkList) malloc (sizeof (LNode));
    L->next = NULL;    // 先建立一个带头结点的单链表
    for (i = n; i > 0; --i) {
        p = (LinkList) malloc (sizeof (LNode));
        scanf(&p->data);    // 输入元素值
        p->next = L->next; L->next = p;  // 插入
    }
} // CreateList_L
```

算法的时间复杂度为：O(ListLength(L))。

#### 5. InsAfter 与 DelAfter 的实现

> 课件页码：P88–P89

```c
Status InsAfter( LinkList& L, ElemType e ) {
    // 若当前指针在链表中，则将数据元素 e 插入在线性链
    // 表 L 中当前指针所指结点之后，并返回 OK；
    // 否则返回 ERROR。
    if ( ! L.current )  return ERROR;
    if (! MakeNode( s, e) )  return ERROR;
    s->next = L.current->next;
    L.current->next = s;
    if (L.tail == L.current)  L.tail = s;
    L.current = s;    return OK;
} // InsAfter

Status DelAfter( LinkList& L, ElemType& e ) {
    // 若当前指针及其后继在链表中，则删除线性链表 L 中当前
    // 指针所指结点之后的结点，并返回 OK；否则返回 ERROR。
    if ( !(L.current && L.current->next ) )
        return ERROR;
    q = L.current->next;
    L.current->next = q->next;
    if (L.tail == q)  L.tail = L.current;
    e = q->data;  FreeNode(q);
    return OK;
} // DelAfter
```

#### 6. 例一：利用线性链表实现 ListInsert_L

> 课件页码：P90

```c
Status ListInsert_L(LinkList L, int i, ElemType e) {
    // 在带头结点的单链线性表 L 的第 i 个元素之前插入元素 e
    if (!LocatePos (L, i-1))  return ERROR;
                        // i 值不合法，第 i-1 个结点不存在
    if (InsAfter (L, e))  return OK;      // 完成插入
    else return ERROR;
} // ListInsert_L
```

即：先把当前指针定位到第 i−1 个结点（LocatePos），再在当前指针之后插入（InsAfter），两步都借助已定义的基本操作完成。

#### 7. 例二：归并有序表 MergeList_L

> 课件页码：P91–P93

```c
Status MergeList_L(LinkList &Lc, LinkList &La,
                   LinkList &Lb, int (*compare)(ElemType, ElemType)) {
    // 归并有序表 La 和 Lb，生成新的有序表 Lc，
    // 并在归并之后销毁 La 和 Lb，
    // compare 为指定的元素大小判定函数
    if ( !InitList(Lc))  return ERROR;    // 存储空间分配失败
    LocatePos (La, 0);  LocatePos (Lb, 0);  // 当前指针指向头结点
    if ( DelAfter( La, e))  a = e;     // 取得 La 表中第一个元素 a
    else a = MAXC;      // MAXC 为常量最大值
    if ( DelAfter( Lb, e))  b = e;     // 取得 Lb 表中第一个元素 b
    else b = MAXC;      // a 和 b 为两表中当前比较元素
    while (!(a==MAXC && b==MAXC)) {  // La 或 Lb 非空
        if ((*compare)(a, b) <= 0) {  //  a≤b
            InsAfter(Lc, a);
            if ( DelAfter( La, e1) )    a = e1;
            else a = MAXC;
        }
        else {   //  a＞b
            InsAfter(Lc, b);
            if ( DelAfter( Lb, e1) )    b = e1;
            else  b = MAXC;
        }
    }
    DestroyList(La);  DestroyList(Lb);  // 销毁链表 La 和 Lb
    return OK;
} // MergeList_L
```

算法要点：只要两个表中还有一个元素（a、b 不全为 MAXC 哨兵值），就比较 a 与 b，把较小者 InsAfter 到 Lc 的当前指针之后，并从相应表中再取下一个元素；取完者以 MAXC 代替。归并结束后销毁 La 和 Lb，因为它们的结点已并入 Lc。

### 六、有序表类型

> 课件页码：P100–P104

回顾例 2-2 的两个算法，可以抽象出“有序表类型”。其抽象数据类型定义如下：

```text
ADT Ordered_List {
    数据对象:  S = { xi | xi ∈ OrderedSet ， i = 1, 2, …, n, n ≥ 0 }
               // 集合中任意两个元素之间均可以进行比较
    数据关系:  R = { <xi-1, xi> | xi-1, xi ∈ S,
                     xi-1 ≤ xi,  i = 2, 3, …, n }
    基本操作:
        LocateElem( L, e, &q,
                    int (*compare)(ElemType, ElemType) )
            // 初始条件：有序表 L 已存在
            // 操作结果：若有序表 L 中存在元素 e，则 q 指示 L 中第一个
            // 值为 e 的元素的位置并返回 TRUE；否则 q 指示第一个大于 e
            // 的元素的前驱的位置并返回 FALSE
        …  …
} ADT Ordered_List
```

其中 compare 是一个**有序判定函数**。注意 LocateElem 的“定位”语义：找到了值为 e 的元素，q 就指向它；找不到时，q 指向第一个大于 e 的元素的前驱，这样 e 应插入到 q 所指结点之后。

**例如**（课件 P102）：有序表 (12, 23, 34, 45, 56, 67, 78, 89, 98)

- 若 e = 45，则 q 指向值为 45 的结点（第 4 个元素，查找成功）；
- 若 e = 88，则 q 指向值为 78 的结点，表示值为 88 的元素应插入在该指针所指结点之后。

**有序表上的两个算法及其复杂度**（课件 P103–P104）：

| 算法 | 对应例子 | 策略要点 | 时间复杂度 |
| --- | --- | --- | --- |
| union | 例 2-1 改用有序表 | 仍用 LocateElem 判定 e 是否已在 La 中，再 ListInsert 插入 | O(n²) |
| purge | 例 2-2 改用有序表 | 只把当前元素 e 与上一次插入的元素 en 比较（值相同者必相邻），无需 LocateElem | O(n) |

两个算法的代码与 2.1 节给出的 union、purge 相同（课件 P103 的 union 以 `InitList(La)` 开头，P104 的 purge 与 P31 的 purge 一致）：例 2-2 因为使用了有序表，把“在整张表中查找重复值”简化为“与相邻元素比较”，时间复杂度由例 2-1 的平方级降为线性级。

### 七、顺序映象与链式映象的对比

> 课件页码：P38–P104（综合）

| 比较项 | 顺序表（顺序映象） | 链表（链式映象） |
| --- | --- | --- |
| 存储单元 | 一组地址连续的存储单元，依次存放各元素（P39） | 一组地址任意的存储单元，结点之间靠指针联系（P59） |
| 逻辑关系的表示 | 以“存储位置相邻”表示有序对，LOC(ai) = LOC(a1) + (i−1)×C（P40） | 以结点中的指针指示后继元素的存储位置（P59） |
| 存取方式 | 随机存取：由寻址公式直接算出第 i 个元素的地址，O(1)（P40） | 顺序存取：找第 i 个元素必须先找第 i−1 个，O(n)（P64、P65） |
| 插入/删除 | 需成片移动元素，平均移动 n/2 或 (n−1)/2 个元素，O(n)（P48–P55） | 只需修改指针，无需移动元素；但按位序操作仍需先定位，O(n)（P67、P71） |
| 存储空间 | 需按 LIST_INIT_SIZE 预先分配，满时 realloc 递增 LISTINCREMENT（P41、P50） | 动态结构，不必预先分配，结点逐个 malloc 插入（P74、P76） |
| 表长 | 有显式的 length 域，求表长 O(1)（P41） | 表长是一个隐含的值，需遍历或用 len 域记录（P81） |
| 元素的“位序” | 位序概念强，可按 i 直接访问 | 位序概念淡化，结点的“位置（指针）”概念加强（P81） |
| 适用场合 | 表长变化不大、经常按位序访问元素 | 表长变化较大、频繁进行插入和删除 |

### 一、一元多项式的表示方法

> 课件页码：P106–P108

形如

```text
Pn(x) = p0 + p1x + p2x² + … + pn xⁿ     ←→     P = (p0, p1, …, pn)
```

的一元多项式，在计算机中可以用一个线性表来表示。

但是对于形如

```text
S(x) = 1 + 3x^10000 – 2x^20000
```

的多项式，上述表示方法是否合适？——不合适：按“系数序列”表示时，两个非零项之间要存放上万个零系数项，空间浪费极大。

一般情况下的一元稀疏多项式可写成

```text
Pn(x) = p1·x^e1 + p2·x^e2 + ┄ + pm·x^em
```

其中：pi 是指数为 ei 的项的非零系数，0 ≤ e1 < e2 < ┄ < em = n。这种多项式可以下列线性表表示：

```text
（ (p1, e1), (p2, e2), ┄, (pm, em) ）
```

即每个元素是“（系数，指数）”二元组，且按指数递增有序排列。

**例如**：P999(x) = 7x³ − 2x¹² − 8x⁹⁹⁹ 可用线性表

```text
( (7, 3), (-2, 12), (-8, 999) )
```

表示。

### 三、一元多项式的实现

> 课件页码：P112–P115

结点的数据元素类型定义为：

```c
typedef struct {      // 项的表示
    float  coef;          // 系数
    int    expn;          // 指数
} term, ElemType;

typedef  OrderedLinkList   polynomial;
    // 用带表头结点的有序链表表示多项式
```

#### 1. CreatPolyn——建立多项式

> 课件页码：P113

```c
Status CreatPolyn ( polynomial &P, int m ) {
    // 输入 m 项的系数和指数，建立表示一元多项式的有序链表 P
    InitList (P);  e.coef = 0.0;  e.expn = -1;
    SetCurElem (h, e);  // 设置头结点的数据元素
    for ( i=1; i<=m; ++i ) {  // 依次输入 m 个非零项
        scanf (e.coef, e.expn);
        if (!LocateElem ( P, e, (*cmp)()) )
             if ( !InsAfter ( P, e ) )   return ERROR;
    }
    return OK;
} // CreatPolyn
```

注意：1. 输入次序不限；2. 指数相同的项只能输入一次。

两个多项式当前项的指数比较，按三种情况分别处理（课件 P115）：

```c
switch (*cmp(e1, e2)) {
    case -1: {  // 多项式 PA 中当前结点的指数值小
                          …  …       break;  }
    case 0: {   // 两者的指数值相等
        e1.coef = a.coef + b.coef;
        if ( a.coef != 0.0 ) InsAfter(Pc, e1);
                    …  …              break;
    }
    case 1: {  // 多项式 PB 中当前结点的指数值小
                           …  …       break;  }
}
```

算法思路（依据上述可见代码整理）：Pa、Pb 各自的当前项以 DelAfter 依次取出，a、b 为当前项的指数，两表都取完（a、b 均等于常量最大值 MAXE）时结束；逐项比较指数：指数小者直接“摘取”并链接到 Pc 的当前指针之后（case −1 处理 Pa 的项，case 1 处理 Pb 的项）；指数相等时把两个系数相加，和不为 0 则用 InsAfter 插入 Pc，和为 0 则该项消失。

## 本章要点回顾

> 课件页码：P116

1. 线性表的逻辑结构特性是数据元素之间存在线性关系；在计算机中表示这种关系的两类不同的存储结构是**顺序存储结构**和**链式存储结构**，用前者表示的线性表简称为**顺序表**，用后者表示的线性表简称为**链表**。
2. 线性表的抽象数据类型 ADT List 含数据对象、数据关系以及结构初始化、结构销毁、引用型、加工型四类基本操作。
3. 顺序映象以“存储位置相邻”表示有序对，LOC(ai) = LOC(a1) + (i−1)×C；顺序表由 elem、length、listsize 三个域描述。
4. 顺序表上的插入、删除需要成片移动元素，平均移动 n/2 与 (n−1)/2 个元素，时间复杂度均为 O(n)；LocateElem 为 O(n)，按位序取元素为 O(1)。
5. 链式映象中结点由数据元素（数据域）和指示后继的指针（指针域）组成；单链表用头指针（或头结点）标识，是顺序存取结构，其 GetElem、ListInsert、ListDelete 均需先扫描定位，时间复杂度 O(n)，插入删除本身只修改指针。
6. 在单链表基础上增加 tail、len、current 三个数据域，并把“位序 i”改为“指针 p”，可把求表长、取当前元素、InsAfter、DelAfter 等操作降为 O(1)。
7. 例 2-1、例 2-2、例 2-3 三个算法的复杂度随实现方式不同而不同：顺序映像下分别为 O(La×Lb)、O(Lb)、O(La+Lb)，链式映像下分别为 O(La×Lb)、O(Lb²)、O(La²+Lb²)。
8. 循环链表判别最后一个结点的条件是“后继是否为头结点”；双向链表的查询与单链表相同，插入和删除需同时修改两个方向上的指针。
9. 有序表类型的 LocateElem 在查找失败时返回第一个大于 e 的元素的前驱位置；对有序表可用“与相邻元素比较”代替整表查找，purge 的时间复杂度降为 O(n)。
10. 一元稀疏多项式可用“（系数，指数）”的有序链表表示，并用 AddPolyn 完成两个多项式的相加。

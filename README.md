# 数据结构课程设计

- `课程设计1code/`：课程设计（一）的 6 道题（1.1～1.6）。
- `课程设计2code/`：课程设计（二）的 4 道题（集合批量增删、文本编辑器、术语词典、图的使用），通过 `main.c` 菜单整合为一个程序，同时保留分题文件。
- `课程设计2实验报告.docx` / `.pdf`：课程设计（二）实验报告，包含题目要求、解题思路、核心代码、完整代码附录、运行截图与心得体会。

课程设计（二）的编译与运行：

```sh
cd 课程设计2code
make
./课程设计2      # 整合版主菜单
```

详见 `课程设计2code/README.md`。
